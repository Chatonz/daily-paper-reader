## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. - **现有方法的不足**：
    1.  **基准缺失**：现有的动态操作基准多仅作为评估平台，缺乏对推理延迟和远期预测的统一研究框架。
    2.  **能力割裂**：增强预测能力的方法往往引入额外计算开销，而专注于推理加速的方法忽视了对未来感知的需求，两者未能有机结合。
    3.  **评估失真**：大多数仿真基准在策略推理时暂停环境，忽略了推理延迟造成的感知-执行间隙，无法真实评估模型在动态场景下的表现。
- **整体含义**：该论文旨在填补这一空白，通过提出新的基准（ReflexBench）和高效的模型（ReflexVLA），系统性地研究和解决VLA模型在“反应关键型操作”中同时实现**快速推理**与**前瞻性决策**的挑战。

### 2. 方法论（核心思想、关键技术细节与流程）

论文的核心方法论分为两个部分：**基准构建（ReflexBench）**与**模型设计（ReflexVLA）**。

**A. ReflexBench：延迟感知的动态操作基准**

1.  **任务列表（Task List）**：包含6个需要快速反应和未来感知的仿真操作任务：
    -   Conveyor Belt Pick-and-Place（传送带拾放）
    -   Ball Catching（接球）
    -   Whack-a-Mole（打地鼠）
    -   Rolling Ball Interception（滚动球拦截）
    -   Ball Throwing（掷球）
    -   Rotating Peg Insertion（旋转插销）

2.  **数据收集（Data Collection）**：采用基于规划的数据收集管道，将每个任务分解为多个子目标。规划器根据物体的实时位置和速度预测其未来轨迹，以规划针对未来状态的动作。对于复杂交互动力学，则训练任务特定的强化学习策略生成演示轨迹。

3.  **延迟感知评估协议（Latency-Aware Evaluation）**：这是ReflexBench的核心特性。
    -   **解耦仿真与控制**：仿真器步进与机器人控制解耦，允许环境在策略计算时继续演化，以模拟真实世界的执行延迟。
    -   **同步与异步推理**：显式建模两种范式。同步推理阻塞执行直至策略计算完成；异步推理将动作执行与策略计算重叠，响应更快但动作可能略有滞后。
    -   **延迟注入机制**：通过“延迟阻塞”机制，可手动指定仿真中的延迟时长，或根据测量的真实世界策略推理延迟和仿真器的**实时因子（Real-Time Factor, RTF）**计算等效延迟并注入评估过程，实现可控的系统性延迟分析。

**B. ReflexVLA：快速且可预测的VLA模型**

ReflexVLA构建于一个紧凑的VLA-Adapter架构之上（融合DINOv2与SigLIP的视觉编码器 + Qwen2.5-0.5B语言骨干），并引入三个关键设计：

1.  **潜在未来预测（Latent Future Prediction）**
    -   **目标**：鼓励策略推理未来状态，学习与下游控制相关的场景动态。
    -   **方法**：在模型输入序列中添加 `H` 个可学习的未来令牌（`H` 与动作块大小一致）。训练时，使用**冻结的DINOv3模型**对未来的观测 `ot+i` 提取语义特征 `yt+i` 作为预测目标。模型通过一个预测头 `f_pred` 将令牌的隐藏表示映射到DINOv3特征空间。
    -   **损失函数**：通过**掩码余弦相似度损失**（公式4）对齐预测特征 `ŷt+i` 与真实未来特征 `yt+i`，总体损失为动作损失 `L_act` 与未来预测损失 `L_future` 的加权和（`λ_future = 0.05`）。
    -   **优势**：相比直接预测像素，预测语义特征避免了计算开销大和关注低级细节的问题，且由于与动作块对齐，额外序列长度很短，计算开销可忽略。

2.  **多帧时间融合（Multi-Frame Temporal Fusion）**
    -   **目标**：从历史观测中捕获短时运动信息，同时避免语言模型侧计算开销的显著增加。
    -   **方法**：在视觉骨干内部进行时间融合。具体来说，从视觉编码器提取**中间层特征**（而非最终层，因其保留了更丰富的局部外观和运动线索）。对每个相机视角和每个图像块，将其在 `T` 个历史帧上的特征序列（构成时间轨迹）进行层归一化和维度压缩，加上**时间位置编码**，然后输入一个**因果时间注意力层**（MHA）进行处理，以防止未来信息泄漏。
    -   **融合特征**：将时间注意力层输出的残差 `Δx` 加到当前帧的最终层特征上，形成最终的视觉特征。这样，语言模型处理的视觉令牌数量与单帧设置完全相同。

3.  **推理延迟优化（Inference Latency Optimization）**
    -   **批量视觉编码（Batched Visual Encoding）**：将多个视角和多个历史帧的图像批量拼接成单个输入，仅执行一次视觉编码器前向传播，大幅减少框架开销并提高GPU利用率。
    -   **CUDA Graph重放**：将视觉编码、时间融合、多模态投影、语言模型推理和动作预测的完整计算图捕获为CUDA Graph。部署时，仅需将新观测数据复制到预分配缓冲区并重放图，消除了逐核启动和运行时调度的开销。
    -   **效果**：这些优化不改变策略架构和学习目标，而是降低了部署开销，将推理延迟从约125 ms降至65 ms。

### 6. 主要结论与发现

1.  **基准与配置验证**：实验表明，在低频下异步推理存在感知-执行错位问题，提高推理频率后异步推理优于同步推理。较大的动作块大小和较短的动作执行步长在异步推理下表现更好。
2.  **动态任务性能**：ReflexVLA在ReflexBench上取得了**50.4%的平均成功率**，超过了所有对比基线（包括7B的OpenVLA-OFT和4B的π0.5），并显著优于其骨干模型VLA-Adapter（从30.3%提升至50.4%）。与动态专用方法PUMA性能相当，但模型仅为其四分之一。
3.  **静态性能保持**：在LIBERO静态基准上，ReflexVLA达到了**97.2%的平均成功率**，与最佳性能的VLA模型持平，证明增强动态能力并未损害其静态操作泛化能力。
4.  **消融研究证明**：
    - **未来预测目标**：使用**冻结DINOv3特征**作为预测目标（+26.0%成功率）远优于使用可训练的视觉目标（-31.9%成功率）。
    - **时间融合位置**：在**中间层特征**进行时间融合（71.7%）优于在最终层特征（68.2%）或使用交叉注意力（66.1%），表明中间层保留了更丰富的运动信息。
    - **推理优化**：批量编码和CUDA Graph不仅将延迟从125.1ms降低到65.0ms，还将成功率从71.7%提升至73.8%，证明了降低延迟对反应关键任务的直接益处。
5.  **真实世界有效性**：在真实机械臂实验中，ReflexVLA在三项任务上的表现均优于SmolVLA，并与轻量级模型PUMA性能相当或更好，展示了其实际部署价值。

- **模型规模与任务范围限制**：尽管1B参数模型效率高，但未在更大规模数据集上验证其扩展性。同时，任务的动态复杂度（如物体速度、干扰程度）可能未覆盖更极端的场景。
- **数据收集成本**：依赖规划器和任务特定的强化学习策略收集数据，对于更复杂、更开放的任务，这种管道构建的难度和成本较高。
