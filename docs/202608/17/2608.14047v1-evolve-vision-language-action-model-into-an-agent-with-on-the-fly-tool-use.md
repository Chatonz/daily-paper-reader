## 摘要
本文集成了端到端的视觉-语言-动作（VLA）模型与智能体工具使用，提出了具备工具使用的智能体机器人（ART）。ART是一个工具注入框架，它能够调整任何VLA模型，以利用现成的工具模块来实现低层视觉、高层可操作性（affordance）和具身增强。与具有完全连续动作解空间的原始VLA模型相比，ART通过工具使用降低了动作解空间的复杂性，这不仅提高了跨任务的泛化能力，还减少了对数据的依赖。为了展示该框架的优势（高泛化性和低数据依赖性），我们首先构建了一个包含30K条工具使用轨迹和动作演示的数据集，该数据集远小于基线方法所使用的数据集。随后，我们设计了一种训练方案，用于在具有挑战性的环境中进行长轨迹工具使用推理。实验表明，在仿真和现实世界任务中，例如在黑暗环境中的新颖视角下进行抓取和放置，ART的成功率比主流基线高出20%。实证结果凸显了基于智能体的方法的优势：模块化工具利用可实现更高效的训练、轻量级部署和新工具的可扩展集成。这种设计促进了鲁棒性、适应性和可扩展性，为VLA系统在复杂现实场景中的实际部署铺平了道路。

## Abstract
This paper integrates end-to-end Visual-Language-Action (VLA) models with agentic tool-use to propose Agentic Robot with Tool-use (ART). ART is a tool-injection framework that tunes any VLA model to leverage off-the-shelf tool modules for low-level vision, high-level affordance, and embodiment enhancement. Compared to vanilla VLA models with a whole continuous action solution space, ART reduces the complexity of the action solution space through tool-use, which not only improves generalizability across different tasks but also reduces data dependency. To demonstrate the advantages (high generalizability and low data dependency) of this framework, we first built a dataset of 30K tool-use trajectories and action demonstrations, which is much smaller than those used by baseline methods. We then designed a training regimen for long-trajectory tool-use reasoning in challenging environments. Experiments show that ART achieves a 20% higher success rate than mainstream baselines on simulation and real-world tasks, such as pick-and-place in the dark at novel viewpoints. Empirical results highlight the benefits of an agent-based approach: modular tool utilization enables more efficient training, lightweight deployment, and scalable integration of new tools. This design fosters robustness, adaptability, and extensibility, paving the way for the practical deployment of VLA systems in complex real-world scenarios.

# 1. 核心问题与研究动机

- 现有 VLA 模型分为两大范式：
  - **模块化方法**（如 RoboTool、RoboScript、RoboCodeX）：通过预定义工具/API 将不同能力解耦，但受限于固定工具集，只能处理较简单的动作输出。
  - **端到端方法**（如 OpenVLA、ECoT、π0）：基于大规模多任务数据训练单一模型，动作精度高，但面对新场景/新任务时需要昂贵的重新训练，且多能力耦合容易导致灾难性遗忘。
- 核心问题：**能否同时获得端到端 VLA 的高精度动作输出能力，以及通过外部工具快速适应新场景的能力？**
- 本文认为：将连续动作空间替换/缩减为离散工具调用，可以降低动作解空间的复杂度，从而提高泛化性并降低数据依赖。

# 2. 方法论：ART 框架

- **核心思想**：将 VLA 模型的观测-动作映射扩展为“推理 → 工具调用 → 增强观测 → 动作生成”的智能体流程。
- **动作空间扩展**：
  - 原始动作空间 A 扩展为 A* = A × R × T，其中 R 为语言推理空间，T 为工具使用动作空间。
  - 工具使用动作为离散 token（每个工具状态为二元激活/非激活），对应词表末尾 N 个 token。
- **优化目标分解**：
  - 整体目标：π* = argmax Pθ(a*1:T | ~o1:T)
  - 分解为两项：Pθ,1(at | o1:t)（原始 VLA 动作生成，基于增强后的观测）和 Pθ,2(ar,t, at,t | ~o1:t)（基于原始观测的推理与工具调用）。
  - 关键分解：最终动作 at 应只依赖于增强观测 ot，而非原始带噪声/损坏的观测 ~ot。
- **工具注入架构**：
  - **工具 token 注入**：将工具动作作为离散 token 与语言生成类似地集成到 next-token prediction 中。
  - **自适应 LoRA 微调**：冻结原 VLA 骨干，只微调 LoRA 模块用于工具推理；在生成最终动作时屏蔽 LoRA 输出，避免工具推理干扰原本的动作能力，从而防止灾难性遗忘。
  - **Action Chunking**：每 H 个时间步执行一次工具推理和选择，而不是每个控制步都调用，提高效率。
- **训练损失**：
  - 工具推理损失 Ltool：基于原始观测的推理 token 和工具动作 token 的交叉熵损失。
  - 动作预测损失 Laction：基于增强观测的动作 token 回归损失（FAST 采用 DCT 离散化动作）。

# 6. 主要结论与发现

- ART 在 LIBERO 上的平均成功率约 **75%**，在 Astribot S1 真实任务上约 **62%**，显著优于 OpenVLA（12%/6.7%）、π0（30%/37%）和 π0-FAST（39%/43%），提升幅度约 **20%**。
- 工具使用能帮助模型应对低光、视觉扰动、affordance 查询和具身状态变化等复杂场景，而传统端到端 VLA 模型在这些场景下性能明显下降。
- 通过 AT 数据集微调得到的工具推理能力可以跨环境（LIBERO → Astribot S1）泛化，说明工具使用是可迁移的。
- 与 ECoT 相比，ART 在视觉扰动下保持稳定性能，而 ECoT 因未见过视觉损坏数据而大幅退化。
- 与 end-to-end fine-tuning（FAST post-trained）相比，ART 在 affordance 和视觉任务上优势明显，证明显式工具推理比直接学习观测-动作映射更高效。
- 总体而言，模块化工具利用带来了高效训练、轻量部署和可扩展集成，增强了 VLA 系统的鲁棒性和实用性。

# 7. 优点

- **方法设计清晰**：通过动作空间扩展 + LoRA 解耦 + 工具 token 注入，能在保留预训练 VLA 动作生成能力的同时赋予工具调用能力，降低灾难性遗忘风险。
- **数据高效**：仅用 30K 轨迹数据即可达到显著性能提升，展示了低数据依赖的优势。
- **数据生成管线有创新**：在现有 VLA 数据上通过“退化任务 + GPT 推理 + 轨迹合成”扩展出工具使用数据，避免昂贵的真实机器人数据采集。
- **通用与可扩展**：框架可适用于不同 VLA 架构，且工具模块可即插即用。
- **实验部分兼顾仿真与真实世界**，并对视觉、affordance、具身三类挑战分别评测，能较全面地展示方法优势。
