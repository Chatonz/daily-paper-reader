## 摘要
请求到交接的间隙有三个耦合来源：请求时刻预期行为的模糊性、动作生成过程中累积的物理状态漂移，以及新动作最终接管控制时的残余不兼容性。BICPO-VLA 依次解决这些问题。首先，一个指令感知的因果历史编码器识别命令和当前任务进度所支持的行为。其次，顺序 Haar 子空间生成将每个动作块分解为互补的成对骨架系数和残差系数，使得能够进行两个专门的生成阶段并随后进行精确重构。通过减少原始动作空间中的迭代细化，它缩短了在新块可用之前机器人持续移动的时间间隔。最后，BICPO 将已知的传出动作推进到实际的交接状态，并在行为匹配的候选之间应用参考相对的 Flow-DPO，使生成的块适应剩余的请求到交接不匹配，而不改变其预期行为。

## Abstract
The request-to-handoff gap has three coupled sources: ambiguity about the behavior intended at request time, physical-state drift accumulated during action generation, and residual incompatibility when the new action finally assumes control. BICPO-VLA addresses them in sequence. First, an instruction-aware causal history encoder identifies the behavior supported by the command and current task progress. Second, sequential Haar subspace generation decomposes each action chunk into complementary pairwise scaffold and residual coefficients, enabling two specialized generation stages followed by exact reconstruction. By reducing iterative refinement in the original action space, it shortens the interval over which the robot continues moving before the new chunk becomes available. Finally, BICPO rolls the known outgoing actions to the actual handoff state and applies reference-relative Flow-DPO among behaviorally matched candidates, adapting the generated chunk to the remaining request-to-handoff mismatch without changing its intended behavior.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型将广泛的视觉和语言知识转化为机器人控制。在异步动作分块（asynchronous action chunking）执行过程中，机器人继续执行旧的动作块，同时模型推演下一个动作块。新动作块在一个运动上下文中被请求，却在另一个上下文中接管控制。
- **核心问题**：请求到交接（request-to-handoff）的间隙包含三个耦合来源：
  1. **行为意图模糊**：请求时刻对预期行为存在歧义；
  2. **物理状态漂移**：动作生成期间累积的状态偏离；
  3. **残差不兼容**：新动作最终接管控制时的边界跳变与运动趋势断裂。
- **关键观察**：一个行为规定的是一个动作实现族（称为"行为条件化动作纤维"），而非唯一轨迹。同一纤维内的成员共享任务语义，但局部运动与交接兼容性不同。
- **整体含义**：可靠控制需要同时满足行为有效性（与指令和任务进度一致）和交接有效性（与控制转移状态兼容）。现有方法未将行为身份、实现结构和交接条件选择三者联合分离。

## 2. 方法论

### 2.1 总体框架：三步因子化

BICPO-VLA 将异步控制问题分解为三个独立阶段，每阶段对应一个不变式：

- **行为条件**：保持任务语义（指令 + 行为状态 + 记忆 + 动作先验）；
- **Haar 坐标**：保持精确动作信息（骨架 + 残差）；
- **交接条件**：仅暴露执行时产生的偏移，供连续性偏好学习吸收。

### 2.2 第一步：指令接地行为识别

- 视觉特征先通过指令条件化注意力路由，过滤与指令无关的视觉证据，再进行历史融合：

  \[
  e_{V_t} = V_t + \text{Attn}(\text{LN}(V_t), L_b, L_b; M_l)
  \]

- 因果历史编码器（Mamba 块）聚合路由后的观测与已执行命令，得到指令相对进度状态 \(z_r\)；
- 相位条件解码器结合检索的长时记忆 \(m_r\)，预测动作先验 \(\mu_r\)；
- 共享条件 \((ℓ, z_r, m_r, \mu_r)\) 固定行为身份，后续阶段仅调整其实现。

### 2.3 第二步：交接条件的 Haar 实现

- **滚动交接上下文**：用冻结的动作历史模型将已知传出命令滚动到实际交接状态 \( \bar{h}_{r,k} \)，并计算其与请求时刻的位移 \( \Delta h_{r,k} \)，组合编码为交接条件 \(g_{r,k}\)；
- **互补坐标**：对偶数长度动作块做一级 Haar 变换，分解为成对骨架（粗粒度、成对运动水平）与互补残差（细粒度、对内变化），且可精确重构（正交变换，无信息损失）：

  \[
  [C; D] = W_H A, \quad A = W_H^\top [C; D]
  \]

- **有序两阶段生成**：骨架阶段先生成块级运动骨架 \( \hat{C} \)，残差阶段以停止梯度的骨架为条件补充局部修正 \( \hat{D} \)，最后经逆 Haar 精确重构完整动作块：
  - 单步反向欧拉即可从噪声恢复目标（线性流匹配路径）；
  - 有监督训练最小化两阶段速度预测误差之和。

### 2.4 第三步：行为识别连续偏好优化（BICPO）

- **同纤维候选对**：在相同行为条件与交接条件下，使用不同流噪声采样两个候选，去除无效候选及参考兼容性差异大的配对；
- **连续性代价**：同时度量零阶交接跳跃 \(J_{\text{jump}}\) 和一阶运动趋势不匹配 \(J_{\text{trend}}\)：
  - \(J_{\text{jump}}(A) = \|a_0 - u_{r+k-1}\|^2_W\)
  - \(J_{\text{trend}}(A) = \|(a_0 - u_{r+k-1}) - (u_{r+k-1} - u_{r+k-2})\|^2_W\)
- **参考相对 Flow-DPO**：两阶段能量基于候选哈达玛系数计算，目标为：
  \[
  L_{\text{pref}} = -q \log \sigma(\beta \Delta_\theta)
  \]
  其中 \( \Delta_\theta \) = 参考模型与当前模型的偏好能量差；仅在代价差超过置信阈值时产生偏好信号；
- **可迁移性**：DPO 目标无需 BICPO-VLA 的指令编码器、Haar 生成器或交接投影器，可直接附加至 π0.5、Legato、RTC 等宿主策略，仅使用其原生条件流能量。
