## 摘要
视觉-语言-动作策略虽具有广泛泛化能力，但缺乏执行时的保障；经典基于模型的规划器虽能尊重运动学与几何约束，但泛化性能较差。我们研究了一种动作条件的联合嵌入预测架构（JEPA）世界模型，能否在执行前预测候选动作块的任务进展与物理风险，以及将这些预测与特定具体化身（embodiment）的基于模型的安全盾相结合，能否为异构机器人提供一个可部署的流程。我们提出了一种滚动时域决策流程：（1）提议器生成K个候选动作块；（2）动作条件的JEPA在冻结编码器潜在空间内，依据具体化身嵌入对每个候选进行前向推演；（3）校准的风险与进展评分头对每次推演进行评分并报告不确定性；（4）确定性逐具体化身安全盾过滤不可行候选；（5）当可行动作集为空时，采用后备阶梯方案。学习到的排序仅对可行动作候选重新排序；执行保障由确定性安全盾和后备阶梯提供。我们在模拟环境（LIBERO-Long）中使用预注册协议进行评估。在600回合配置中，完整框架比仅安全盾基线提高了成功率，并在匹配召回率下减少了碰撞漏报。文中还报告了在目标机器人与边缘加速器上的部署效率测量。真实机器人实验和离线重排显著性检验留待未来工作；详见论文中的披露。

## Abstract
Vision-language-action policies generalize broadly but provide no execution-time guarantees; classical model-based planners respect kinematic and geometric constraints but generalize poorly. We study whether an action-conditioned Joint-Embedding Predictive Architecture (JEPA) world model can predict, before execution, both task progress and physical risk for candidate action chunks, and whether coupling these predictions to an embodiment-specific model-based safety shield yields a deployable pipeline for heterogeneous robots.   We propose a receding-horizon decision pipeline: (1) a proposer produces K candidate action chunks; (2) an action-conditioned JEPA rolls each candidate forward in a frozen-encoder latent space conditioned on an embodiment embedding; (3) calibrated risk and progress heads score each rollout and report uncertainty; (4) a deterministic per-embodiment safety shield filters inadmissible candidates; (5) a fallback ladder handles empty-admissible-set cases. The learned ranking only reorders admissible candidates; enforcement guarantees come from the deterministic shield and fallback ladder.   We evaluate with a pre-registered protocol in simulation (LIBERO-Long). In 600-episode configurations the full framework improved success over a shield-only baseline and reduced collision false negatives at matched recall. Deployment-efficiency measurements on target on-robot and edge accelerators are included. Real-robot experiments and an offline reranking significance test remain future work; see the paper for disclosures.

## 1. 核心问题与整体含义

- **研究动机**：
  - 视觉-语言-动作（VLA）策略（如 RT-2、OpenVLA、π0）虽然泛化能力强，但本质上是模仿学习，**无法在执行前预测动作的后果**，也不具备“弃权”（abstain）机制，因此缺乏执行时的安全保证。
  - 经典模型基规划器（MPPI、CEM、预测安全滤波器）严格尊重运动学与几何约束，但其“下一步会发生什么”的推理局限于手工设定的动力学模型，**无法处理语义任务进展、遮挡、打滑等视觉失效模式**，泛化能力弱。
  - 潜空间世界模型（JEPA）被视为桥梁：它不预测像素，而是预测未来表征，能在计算成本和语义抽象之间取得平衡。
- **核心问题**：能否用一个动作条件 JEPA 世界模型，在执行前预测候选动作的任务进展与物理风险，并将这些预测与一个“具体化身专属”的模型安全盾耦合，从而为异构机器人提供可部署且可校准的安全决策层？
- **整体含义**：论文提出了一个滚动时域决策架构——学习组件（JEPA 世界模型、风险头）只负责**对可行动作进行排序**，而真正的安全保证完全来自**确定性安全盾**和**回退阶梯**。学习模型永远不能扩大“可行动作集合”。这一分离是全文的设计契约（Proposition 1），也是其可辩护性的基础。

## 2. 方法论

### 2.1 核心思想
- 在每次控制周期内：
  1. 对观测进行一次编码；
  2. 由混合提议器（VLA 策略、MPPI/CEM、技能库）生成 K 个候选动作块；
  3. 动作条件预测器在冻结编码器的潜空间中，基于具体化身嵌入 `erob` 对每个候选滚动推演；
  4. 风险/进展头输出 `{pprog, pcoll, pstuck, pfail, u}` 并给出校准的不确定性；
  5. 标量评分 `Jk` 对候选排序；
  6. 确定性安全盾 `Cemb` 过滤所有违反硬约束的候选；
  7. 若可行动作集为空，触发回退阶梯（安全停止 → 恢复 → 重新规划 → 上报人工）。

### 2.2 关键公式与算法
- **观测与具体化身**：
  - 观测 `ot = {It, Dt, st, g}`（RGB历史、深度、本体感觉、目标）；
  - 具体化身 `erob = (K, G, L, D)`（运动学、几何、执行器极限、动力学包线）。
- **选择问题**（式 4）：
  - `k* = argmin_k Jk`，约束 `Cemb(a(k), erob) = 1`。
  - Proposition 1（盾支配性）：执行动作一定满足 `Cemb`；学习参数无论好坏都不能改变强制约束集，只能重排可行动作内部顺序。
- **潜空间预测**（式 5–7）：
  - 冻结编码器 `zt = Eθ(ot)`；
  - 动作条件预测器 `ẑ(k)_{t+h} = Fϕ(zt, a(k), erob)`，使用 AdaLN/FiLM 注入动作和具体化身，自回归滚动；
  - 损失为多步预测特征与 EMA 目标编码器的 stop-gradient 输出之间的 `L2` 距离；教师强制从早期目标逐步退火到自预测，以缓解训练/测试错配。
- **风险与进展头**（式 8–10）：
  - 输出四类风险概率和不确定性 `u`；
  - 总损失 `L = λpr Lpred + λpg Lprog + λc Lcoll + λs Lstuck + λf Lfail + λcal Lcal + λrk Lrank`；
  - 风险头使用聚焦二元交叉熵，因正类稀少且更关注假阴性；
  - 排序损失为成对 margin loss，受“critic 需要成对进展监督”的启发。
- **评分规则**（式 12）：
  - `Jk = -λp p_prog + λc p_coll + λs p_stuck + λf p_fail + λu u + λctrl c(a)`；
  - `u > 0` 使系统在不确定性高时风险厌恶。
- **安全盾**（式 13）：
  - `Cemb = c1 ∧ ... ∧ c8`，包括：扫掠体积碰撞、关节极限、速度/加速度极限、稳定/支撑多边形、地形坡度、**停止距离可行性（递归可行性）**、自碰撞、地理围栏；
  - 盾内**没有任何学习参数**，且是逐具体化身的。
- **校准机制**：温度缩放 + 集成/MC-dropout 不确定性 + 共形包装（conformal wrapper），并由不确定性门控决定是否干预（仅在不确定高或前两名接近时才调用世界模型）。
- **执行架构**：提议器、盾、安全停止控制器在机器人端实时运行；世界模型滚动可异步在边缘/云端运行；若排名过期或链路失败，系统退化为“提议器+盾”，约束集不变。
