## 摘要
长时程机器人操作要求机器人既能可靠地执行单个技能，又能在扩展任务中有序地编排这些技能。大多数分层视觉-语言-动作（VLA）模型通过单次前向传播做出每个此类决策，没有机制为困难或重要的选择分配额外的计算。我们提出了 $τ_0$-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成形式化为一个可扩展计算的推理问题。在每个推理步骤中，高层策略利用执行记忆生成子任务，并在必要时对其输出进行替代方案的搜索，然后才最终确定。然后，低层策略在多种机器人实体上执行生成的子任务。该策略使用多模态协同训练，在 40,115 小时的异构真实世界数据上进行训练。在领域内和分布偏移的设置中，分配额外的测试时计算能大幅提高下一子任务预测的准确性，并且这些收益转化为长时程机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

## 1. 论文的核心问题与整体含义

长时程机器人操作（如打扫房间、做饭、制作奶茶）既要求机器人可靠地执行单个技能，又要求其能在数分钟甚至数小时的扩展任务中有序地编排这些子任务。现有的大多数分层视觉-语言-动作（VLA）模型在面临每个高层决策时，仅执行一次前向传播，以固定推理预算直接将当前观测与执行历史映射到下一个子任务，缺乏根据决策难度动态分配额外计算量的机制。这意味着：模型既不会比较多个候选子任务的优劣，也不会通过子任务预期将产生的物理状态来评估其后果。一旦决策错误，往往只有在该子任务已经执行完毕、环境已被改变之后才被察觉，此时重新规划已无法挽回因错误决策付出的代价。

本文的核心洞察在于：**长时程执行的核心瓶颈不再是分层动作接口是否可用，而是生成下一个子任务所使用的推理过程**。为此，论文提出 τ0-VLA，将高层子任务生成构建为一个推理时（test-time）的计算可扩展问题——在决策时通过世界模型对候选子任务进行后果预测与评估，允许推理预算随决策难度增长。这与大语言模型中测试时计算（如 OpenAI o1、DeepSeek-R1）的基本思想一脉相承：把关键决策的"思考"环节显式地放到推理阶段。

## 2. 论文提出的方法论

### 2.1 整体架构

τ0-VLA 是一个分层 VLA 系统，包含两个策略组件，在每个推理步骤中依次应用：

- **高层策略**：负责任务进度跟踪、执行记忆维护、决定是否调用额外的测试时计算（TTC）、生成当前子任务。
- **低层策略**：将当前多视角观测与高层生成的子任务映射为具体的机器人动作序列（动作块）。

### 2.2 高层策略

高层策略 µ 由四个模型组成：**提案模型 P**、**世界模型 W**、**价值模型 V** 和**反思模型 F**。

**（1）提案模型（Proposal Model）**：接收当前上下文 h_t = （任务指令 ℓ、携带的执行记忆 M_{t-1}、上一个子任务 z\*_{t-1}、当前多视角观测 o_t），更新执行记忆并直接生成一个子任务提案 z^dir_t。同时，从同一前向传播产生的 token 置信度计算自适应路由决策 g_t ∈ {0, 1}：g_t = 0 走快速路径直接采用提案；g_t = 1 则触发 TTC。

**（2）世界模型与价值模型**：对于搜索中的任一候选分支，世界模型基于头部相机的 RGB 图像和候选子任务，预测该子任务完成时的终止图像 ̂o = W(õ, z)；价值模型在该预测图像的基础上，结合全局任务指令与候选子任务，给出 0-1 标量评分 v = V(ℓ, z, ̂o)。

**（3）测试时搜索过程**：当路由决定触发 TTC 时，系统执行束搜索（beam search），在候选子任务序列空间内进行递归扩展，核心步骤为：

> 1. 从根节点出发，以当前观测为上下文，每个保留分支独立地调用提案模型 N 次，生成 N 个候选子任务；
> 2. 对每个候选子任务用世界模型预测终止图像，再用价值模型打分；
> 3. 通过全局排名保留 Top-B 分支（累积分数最高的 B 个），递归扩展到深度 D；
> 4. 搜索结束后，反思模型以保留分支摘要和真实上下文为条件，生成最终子任务 z\*_t——该输出可以与某个保留提案相同，但不受候选集限制。

搜索过程中产生的所有记忆均为分支局部记忆，不会覆盖持久执行记忆 M_t。

### 2.3 低层策略

低层策略将预训练视觉-语言骨干（Qwen3.5-2B）与 Mixture-of-Transformers（MoT）动作专家相结合。其核心设计包括：

- **统一的 40 维状态/动作空间**：覆盖末端执行器位姿（位置 + Rot6D 方向）、夹爪、腰部、移动基座、左右臂关节等多种控制通道，通过样本级状态/动作掩码选择合法通道，支持固定基座、双臂协调和移动全身控制多种模式。
- **掩码流匹配（Masked Flow Matching）**：对不同实体不激活的动作通道进行掩码处理，训练目标为（式 15）：
  L_FM = E[ (1/H·tr(M)) · Σ_{j=0}^{H-1} || M·v^τ_{θ,t+j} − u_{t+j} ||₂² ]
  式中 M 为对角掩码矩阵，τ 为共享流时间，v^τ 为预测的速度场，u 为目标速度。推理时从高斯噪声初始化动作块，通过欧拉积分从 τ=1 到 τ=0 生成动作，H=30，10 步均匀欧拉更新。

### 2.4 训练

- **低层策略**：按下述三个阶段训练：① 知识隔离协同训练（MoT 动作专家注意力作用于视觉-语言骨干，但动作损失梯度不反传到骨干）；② 端到端协同训练；③ 任务特定微调。
- **高层策略**：提案、价值、反思模型从同一 Qwen3.5-9B 初始化的 VLM 检查点独立微调，世界模型从 Step1X-Edit 初始化。值得强调的是，高层策略的监督信号全部自动生成，无需额外人工标注——通过扰动物理演示中的执行记忆构造五类训练样本（within-subtask、transition、catch-up、rollback、error-think），涵盖记忆对齐、滞后、超前和失败恢复等场景。

## 6. 论文的主要结论与发现

1. **层级 TTC 显著提升长时程任务闭环成功率**。在四任务平均 SR 上，分层系统（Plan Once）达到 45.00%，远高于直接执行（27.50%）和外部基线（π0.5 为 22.50%，GR00T 为 2.50%，LingBot-VLA 为 0.00%）。

2. **TTC 进一步提升性能**。在闭环物理实验中，Make Milk Tea 的 SR 从 5/10 提升到 7/10，Book Organization 从 6/10 提升到 9/10，Clean Room 从 5/10 提升到 7/10。

3. **TTC 在下一子任务预测精度上全面超越 Plan Once 和 Best-of-N**。以 Book Organization OOD 为例，TTC 达到 74.0% 精度，而 Plan Once 为 50.0%，Best-of-N 为 57.5%。

4. **额外计算量与预测精度呈饱和关系**。在低计算预算区间，精度提升非常显著；边际收益随计算量增加逐步衰减，最终趋近平台期——这印证了 TTC 在中等计算预算下具有优越的计算-精度权衡，但增益最终有限。

5. **执行记忆对长时程任务至关重要**。执行记忆对于跨房间转换、不可见状态（如调味是否已加入）的追踪和失败恢复尤为关键，直接执行策略容易重复加盐或完全跳过关键步骤。

6. **低层策略具有较强的跨实体泛化能力**。τ0-VLA 在 Collect Laundry（10/10 SR）和 Tidy Makeup Table 三个任务组（10/10、9/10、10/10）上均超过所有基线。

6. **实验设计严密**：物理机器人试验有统一重置策略、终止条件、时限；进度评分有明确的前置依赖图规则；程序化质量过滤管线清晰，说明充分。

## 8. 不足与局限

1. **算力信息缺失与可复现性受限**：论文没有报告 GPU 型号、数量、训练时长、TTC 搜索单次决策的实际时延等关键工程指标，这给学术复现和工程成本评估带来显著困难。

2. **物理试验样本量偏小**：每任务每方法仅 10 次物理试验，在报告 4/10 与 5/10 这类差异时，置信区间重叠较大，统计显著性存疑；缺少多次运行之间的方差报告（如多次 rollout 的平均与置信区间）。

3. **测试时计算仅在部分任务评估了闭环**：TTC 闭环验证仅涉及 Make Milk Tea、Book Organization 和 Clean Room，未覆盖全部长时程任务；TTC 带来的收益在更复杂任务中是否延续缺乏证据。

4. **模型规模与消融深度有限**：高层策略固定为 Qwen3.5-9B、低层骨干固定为 Qwen3.5-2B，没有比较不同骨干规模对 TTC 效率的影响；对搜索参数（N、B、D）各自的影响只做了整体敏感性分析，没有单独消融每个参数；反射模型的贡献未单独消融。

5. **LLM-as-Judge 协议潜在偏差**：GPT-5.4 作为裁判本身可能存在对特定表达风格的倾向性；"equivalent" 判定依赖裁判对物理状态转换的理解，裁判失误会直接影响高层策略评估精度，但论文未验证裁判协议与人工判定的一致性。

6. **低层策略任务特定微调的局限性**：论文承认对每个部署任务进行了任务特定微调，这会引入额外的数据成本，也使"基础模型"的零样本推理能力表述需要谨慎解读；此外，内部数据占训练主体（约 23.4K/40.1K 小时），公开数据的可验证性不如纯开放数据集。

7. **世界模型预测误差的级联放大问题**：TTC 搜索在深度扩展时，子节点的上下文完全依赖前一层的预测图像，多步预测误差会沿搜索树传播和放大；论文虽通过反思模型部分缓解了该问题，但未量化分析预测误差随深度增加的衰减规律。
