## 摘要
视觉-语言-动作（VLA）模型的实际部署常常受到效率-性能权衡、跨实体泛化和执行平滑性的瓶颈制约。我们提出了NebulaVLA，一种异步双频架构，它将高级语义推理与低级动作控制解耦，优化了计算资源和模块化。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑约束来强制运动学连续性。综合评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速了约2.7倍。这种异步设计使得实际机器人能够实现高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：机器人操作正从模块化流程转向端到端学习，VLA（Vision-Language-Action）模型通过统一感知、语言和控制，实现了自然语言指令跟随与复杂任务执行。然而现有VLA模型在真实世界部署中面临三大瓶颈：
  1. **效率-性能权衡**：单体同步架构采用统一的时序分辨率，无法同时支持低频语义推理与高频电机控制。
  2. **跨本体泛化不足**：将连续运动学映射到离散 token 需要巨大词表和大量演示数据，难以统一异构平台的动作语义。
  3. **动作平滑性挑战**：异步实时推理与动作块生成之间的时间错配，导致执行抖动和轨迹不连续。
- **核心含义**：NebulaVLA 引入"快慢认知"双频架构，系统性地解决了效率、泛化和平滑性三大问题，为 VLA 模型的实际部署提供了高效且响应的控制方案。


## 二、论文提出的方法论

### 核心思想
NebulaVLA 受 Kahneman 的"快慢思维"认知范式启发，采用**异步双频架构**：将审慎推理（System 2，10 Hz VLM）与反应式控制（System 1，20 Hz DiT 生成器）解耦，以优化计算延迟并支持分布式部署。

### 关键技术组件

1. **异构双频架构**：
   - **System 2（S2）**：基于 Qwen3-VL，以约 10 Hz 处理自然语言指令和稀疏视觉输入，通过可学习 token 提取隐藏层特征，输出抽象动作引导。
   - **System 1（S1）**：以约 20 Hz 运行，基于 Diffusion Transformer（DiT）实现低层动作控制，利用 Q-Former 压缩 S2 引导与高频视觉输入，最终通过去噪过程输出执行动作。
   - 两个系统通过显式数据流规范解耦，原生支持分布式部署，实现低交互延迟。

2. **GESTURE-7 动作表示**：提出 7 维连续末端执行器向量 [x, y, z, r, p, w, gesture]，其中 (x,y,z) 为笛卡尔位置（厘米），(r,p,w) 为姿态角（度），gesture 为自然语言关键词（如 "grasp"、"push"），实现异构机器人间统一动作语义，并支持强化学习。

3. **Guide Action 机制**：
   - 受图像外推（Image Outpainting）启发，将块拼接嵌入生成流程。
   - 基于上一块未执行动作（如 a₄–a₇）作为引导条件，使新块起始状态与已执行轨迹对齐。
   - 去噪过程中通过掩码约束强制保留已知动作：
     $$A^{t-1}_{full} = M \odot A^{(t-1)}_{prior} + (1 - M) \odot A^{t-1}_{noisy}$$
   - 引导动作数在训练中从 0~3 随机采样以适应推理延迟。

### 三阶段训练流程
- **阶段 1（S2 监督微调）**：包含空间接地（末端位姿回归、2D 关键点回归）、轨迹预测（2D 航点、3D 轨迹点）和链式推理（CoT 子任务分解 + GESTURE-7 轨迹生成）。
- **阶段 2（S2 强化学习）**：基于 GRPO，保留相同任务集，采用 GESTURE-7 距离、关键点定位、航点 DTW、轨迹和格式奖励函数。
- **阶段 3（S1 监督微调）**：联合优化 S2 与 S1，采用 L2 损失，损失仅在掩码 M=0 的新生成区域计算，保持训练-推理频率对齐。

## 七、优点

1. **架构创新性强**：异步双频设计受心理学"快慢思维"启发，将语义推理与动作控制解耦，是系统工程思路的巧妙体现；原生支持分布式部署，利于边缘计算场景。
2. **统一动作表示设计巧妙**：GESTURE-7 通过自然语言关键词映射统一异构机器人动作语义，粒度细化到"厘米/度"级量化，降低学习负担；可扩展词表，兼容灵巧手与夹爪。
3. **平滑性约束内生化**：Guide Action 将轨迹连续性约束嵌入扩散生成过程而非事后平滑，从生成机制上消除块间抖动，具有原理性优势。
4. **实验设计较为全面**：同时覆盖仿真（大规模基准、多扰动维度）和真实世界（延迟、平滑性、成功率），并有消融验证各组件的贡献。
