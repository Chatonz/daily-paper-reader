## 摘要
世界行动模型（WAMs）联合预测未来行动和环境的演变。在每次推理时，WAM生成一组行动，机器人执行固定的前缀，然后重新规划。我们认为，这种固定的执行范围与执行动态不匹配：块的可靠性因任务阶段而异，因此何时重新规划取决于累积执行的结果，而不是步骤计数。我们提出了TempoWAM（通过在线监控进度来定时执行），一种用于WAM的轻量级即插即用执行方案。递归进度监控器首先从当前观察、任务指令、剩余行动和执行历史中估计任务进度；然后，自适应执行协议评估块是否在推进任务，以决定是否需要重新规划。为了弥合训练与部署之间的差距，该协议通过任务相关的校准因子进行校准，并在线调整。在LIBERO、RoboTwin和真实世界任务上的实验表明，TempoWAM持续改善了WAM执行的效率-成功权衡。在真实机器人上，它在简单任务上将WAM推理减少了26.9%，同时保持了成功率，并在困难任务上将成功率提高了13.3个百分点。

## Abstract
World Action Models (WAMs) jointly predict future actions and the evolution of the environment. At each inference, a WAM generates a chunk of actions and the robot executes a fixed prefix before replanning. We argue that this fixed execution horizon is poorly matched to execution dynamics: the chunk reliability varies across task stages, so when to replan depends on the result of accumulated execution, not on the step counts. We propose TempoWAM (Timing Execution by Monitoring Progress Online), a lightweight plug-and-play execution scheme for WAMs. A Recurrent Progress Monitor first estimates task progress from the current observation, task instruction, remaining actions, and execution history; and an Adaptive Execution Protocol then evaluates whether the chunk is advancing the task to decide if replanning is needed. To bridge the training-deployment gap, the protocol is calibrated by a task-dependent calibration factor with online adaptation. Experiments on LIBERO, RoboTwin, and real-world tasks show that TempoWAM consistently improves the efficiency-success trade-off of WAM execution. On real robots, it reduces WAM inferences by 26.9% on easy tasks while maintaining success, and improves success by 13.3 points on difficult tasks.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界行动模型（WAMs）是机器人操作领域的重要范式，它在一个统一模型中联合预测未来动作与环境演化。每次推理时，WAM 生成一段动作块（action chunk），机器人执行其中的固定前缀后触发重新规划（replanning）。
- **核心问题**：**固定执行范围（fixed execution horizon）与任务执行动态不匹配**。动作块的可靠性随任务阶段变化：在简单阶段，块在多个步长内保持准确；在困难阶段，误差会快速累积。因此，何时重规划应取决于累积执行的结果，而非预设的步数计数。
- **现有方法的不足**：已有自适应执行方法多依赖代理指标（action entropy、预测一致性、注意力权重等），并未直接度量**任务是否在推进**。一个动作序列可能平滑但毫无进展，高熵动作也可能仍在推动任务。对 WAM 而言，执行决策应建立在任务进展的基础上，而非块的表面合理性。

## 2. 提出的方法论

### 2.1 核心思想：TempoWAM（Timing Execution by Monitoring Progress Online）

- 一种**即插即用、轻量级**的 WAM 自适应执行方案，完全作用于执行层，**不修改或重新训练底层 WAM**。
- 核心逻辑：通过在线估计任务进度，决定是继续执行当前 chunk 中剩余的候选动作，还是丢弃并触发重新规划。

### 2.2 Recurrent Progress Monitor（RPM，循环进度监控器）

- **输入**：当前观测 `o_t`、剩余动作候选 `c_rem`、候选前缀长度 `n_t`、上一进度估计 `v_{t-1}`、任务指令 `ℓ`。
- **输出**：任务进度估计 `v_t ∈ [0,1]`，接近 0 表示任务早期，接近 1 表示接近完成。
- **编码方式**：
  - 观测通过冻结的 WAM 视觉骨干 + 轻量 MLP 投影；
  - 候选动作前缀由循环编码器处理，并加入前缀长度嵌入；
  - 历史进度通过学习投影注入；
  - 使用 GRU 聚合多模态信息并输出最终进度估计。

### 2.3 Adaptive Execution Protocol（AEP，自适应执行协议）

- **进度率比较**：计算当前进度率 `ρ_cur` 与所需进度率 `ρ_need` 的比值 `r_t`：
  - `ρ_cur` = 每步实际推进的进度；
  - `ρ_need` = 剩余步数平均所需达到的进度率；
  - `r_t < 1` 表示剩余动作推进过慢，应触发重规划；`r_t ≥ 1` 则继续执行。
- **二阶段校准机制**：
  - **离线校准**：从任务演示中按最小二乘拟合每集校准因子，取中位数作为任务初始化值。
  - **在线自适应（两时间尺度）**：
    - 集内：EMA 更新校准因子，补偿训练-部署偏差和进度估计漂移；
    - 集间：根据近期成功率调整缩放因子 `δ′`，成功率低于目标则更频繁重规划，高于目标则提升效率。

### 2.4 训练目标

- 监督标签：`y_u = u/T_ep`（当前步数/总步数）。
- 损失函数：BCE 进度预测损失 + 平滑性正则 + 历史一致性正则（HCR）。
- 关键特色：**概率式 teacher forcing（ptf=0.5）**，平衡训练稳定性和部署时的自反馈误差暴露。

## 6. 主要结论与发现

1. **固定执行范围是次优的**：块可靠性是阶段依赖的，任何固定执行方案都无法匹配所有阶段的需求。
2. **任务进度是自适应执行的自然准则**：比不确定性代理指标更直接地反映执行的实际效果。
3. **TempoWAM 显著改善效率-成功权衡**：
   - **RoboTwin**：短任务上维持/提升成功率并减少调用；长任务上成功率提升（clean 86.93→88.47，randomized 84.47→85.33），同时减少执行步数；整体成功率 +1.18 点，调用次数 +1.67（但在短任务上 −0.46）。
   - **LIBERO**：保持成功率（97.25% 不变）的同时将调用从 14.88 降至 12.46。
   - **真实机器人**：简单任务调用减少 26.9% 且成功率保持；困难任务成功率提升 13.3 个百分点。
4. **跨骨干即插即用成立**：TempoWAM 转移至 Motus 无需重新训练即可提升成功率（move_can_pot 提升 59 点）。
5. **在线校准机制有效**：成功率门控的自适应能自动区分任务难度，在超额成功的任务上放松协议以提效，在成功率不足的任务上收紧协议以保成功。

## 7. 优点

- **即插即用**：无需修改或重训骨干 WAM，直接附加在执行层即可生效。
- **进度感知**：直接基于任务推进程度做决策，而非间接的不确定性代理，语义明确。
- **轻量高效**：RPM 计算开销极小（占一次优化 WAM 调用的 0.34%~3.54%）。
- **双时间尺度校准设计精巧**：离线初始化 + 集内 EMA + 集间成功率门控，兼顾了任务先验、集内漂移和跨集难度调节。
- **诊断实验有价值**：通过时间反转构造矛盾监督，验证了时间标签的有效条件，说明学习的映射是基于视觉状态而非步数计数，论证严谨。
- **部署优化数据翔实**：报告了从 PyTorch 到 TensorRT 到 FP8 混合精度等多级优化后的推理延迟。

## 8. 不足与局限

- **时间标签的有效性受限**：`y_u = u/T_ep` 仅在观测序列"进度单调无混叠"（progress-monotonic without aliasing）时有效。周期性或对称性任务会破坏该假设，作者承认这需要相位分解或语义进度监督，留待未来工作。
- **真实机器人实验覆盖面较小**：仅 3 个任务、每任务 30 次试验，统计显著性未报告，难以排除偶然性。
