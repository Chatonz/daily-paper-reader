## 摘要
近期的视觉-语言-动作（VLA）模型几乎普遍将机器人本体感觉状态作为输入，但以不兼容的方式接入——序列化为文本提示、投影到视觉-语言前缀中，或直接馈送给动作专家——且几乎总是作为单一当前帧。三个问题仍然悬而未决：（1）当前状态是否以及在哪类任务上实际改善了闭环控制；（2）状态历史有多大帮助，其益处是否反映真实的时序变化而非额外的条件化容量；（3）状态应进入模型的哪个部分——视觉-语言骨干网络还是动作生成模块。我们通过在流匹配VLA上进行受控实验来回答这些问题，全程固定骨干网络、训练数据、动作表示和评估协议。我们在匹配的实现细节下实现了五种代表性接口——离散状态提示、VLM前缀、动作前缀、状态专家和特征调制——并在跨越三个任务家族的45个原子任务加上20个复合任务上评估它们；然后我们扫描状态历史长度从1到96帧，以检验历史状态信息如何影响模型性能。实验为所有三个问题提供了系统性的答案，并提炼为可测试的感知状态VLA设计原则。

## Abstract
Recent Vision-Language-Action (VLA) models almost universally take robot proprioceptive state as input, yet wire it in incompatible ways -- serialized into text prompts, projected into the vision-language prefix, or fed directly to the action expert -- and almost always as a single current frame. Three questions remain open: (1) whether, and on which tasks, current state actually improves closed-loop control; (2) how much state history helps, and whether its benefit reflects genuine temporal variation rather than added conditioning capacity; and (3) where state should enter the model -- the vision-language backbone or the action-generation module. We answer these questions through controlled experiments on a flow-matching VLA, fixing the backbone, training data, action representation, and evaluation protocol throughout. We implement five representative interfaces -- discrete state prompt, VLM prefix, action prefix, state expert, and feature modulation -- under matched implementation details, and evaluate them on 45 atomic tasks spanning three task families plus 20 composite tasks; we then sweep the state-history length from 1 to 96 frames to examine how historical state information affects model performance. The experiments yield systematic answers to all three questions, distilled into testable design principles for state-aware VLAs.

  - **RQ3**：状态应该注入模型的哪个部分——视觉-语言骨干网络还是动作生成模块？

## 2. 论文提出的方法论

**核心思想：**
- 采用 **流匹配VLA**（π0.5）作为统一测试平台，将其与流匹配动作专家结合，作为所有实验的基础策略。
- 将本体感觉状态的接入方式分解为三个受控变量：**状态表示**（离散或连续）、**历史长度 K**、**注入位置**（VLM侧或动作侧）。
- 保证所有接口共享相同的动作生成目标、数据流水线和训练配方，仅改变状态窗口的表示和注入方式，从而使性能差异可归因于状态设计本身。

**状态表示：**
- 每个原始状态帧  $s_q \in \mathbb{R}^{16}$ 包含末端执行器位置和四元数（基座坐标系）、移动基座位置和四元数（世界坐标系）、以及两个夹爪关节位置。
- 连续接口的每帧状态通过一个两层投影器独立编码为单个连续状态token：$h_i = \phi_2(\text{Swish}(\phi_1(s_i)))$，其中 $\phi_1$ 将零填充后的32维输入提升到宽度 $d$，$\phi_2$ 保持该宽度。VLM前缀使用 $d=2048$，动作侧接口使用 $d=1024$，以匹配宿主模块的隐藏宽度。
- 离散状态提示（State Prompt）将当前状态每个维度量化为256个bin，通过分词器序列化为约66个提示token，不添加可训练参数，且只支持当前帧。

**五种状态接口：**
1. **离散状态提示（sp）**：复用原生文本入口，状态token与语言指令拼接，经预训练词嵌入空间，参数成本为零。
2. **VLM前缀（vp）**：连续状态token插入双向VLM前缀中（图像和语言token之后），先参与多模态上下文建模，再间接影响动作生成。
3. **动作前缀（ap）**：状态token放在因果动作后缀中、噪声动作token之前，在每个去噪步骤直接参与动作专家的速度场预测，是状态到动作的最直接路径。
4. **状态专家（se）**：添加独立的状态处理流（自己的Transformer栈），与VLM和动作专家并行，并在生成期间与动作模块交换信息，容量最大（单帧时增加约1.99亿参数）。
5. **特征调制（fm）**：状态作为独立条件记忆，通过交叉注意力读取，并预测每特征尺度 $\gamma$ 和偏移 $\beta$ 对动作特征进行持续调制：$\text{Mod}(z;S) = (1+\gamma(z,S))\odot z + \beta(z,S)$。

**训练与推理成本分析：**
- 论文提供了理论边际计算开销的解析推导（附录C），区分训练/推理成本、token数量、参数容量和实际吞吐量等不同概念。
- sp 虽然不增加参数，但因约66个语义token遍历VLM，训练侧开销最高（约1114训练GFLOPs/样本）；连续接口训练成本大幅降低（vp:16.9、ap:3.5、se:2.6、fm:45.4），推理成本各有差异（ap因每个去噪步骤重复处理状态token，推理开销相对较高）。

## 3. 实验设计

**基准与场景：**
- 使用 **RoboCasa365** 仿真平台，包含多样的厨房场景、机器人初始配置、物体实例和操控任务。
- 视觉输入包含三个视角：左外部相机、右外部相机和腕部相机。

**原子任务基准（Atomic Benchmark）：**
- 将45个原子任务按操控语义（非按模型性能）预分为三个家族：
  - **A（重排列/抓放）**：探测末端执行器和移动基座的大范围定位能力。
  - **B（关节物体交互）**：探测持续接触和运动相位建模。
  - **C（旋钮/开关/电器控制）**：小工作空间内高局部精度要求。
- 每个家族训练一个独立的“类别专家”，每个任务进行50次闭环 rollout，固定任务列表和种子计划。

**复合任务基准（Composite Benchmark）：**
- 使用 RoboCasa365 的 `lifelong_learning_phase2` 设置：20种任务类型，每个在一个episode内串联2~3个原子子目标。
- 每个接口在一个策略上联合训练所有20种类型，评估仅保留新episode（属于分布内复合控制）。
- 默认使用末端执行器位姿状态；另用关节角度状态重复关键比较（动作空间始终为末端执行器增量），以隔离状态坐标系的影响。
- 每个复合任务进行25次闭环 rollout，固定种子计划。

**对比方法：**
- 无状态基线（NS）+ 五种状态接口（sp、vp、ap、se、fm），以及历史长度 K 从1到96帧的多种配置。
- 使用“重复当前状态”（repeat-current）作为 slot-matched 对照，以区分真实历史时序内容与额外条件token容量的作用。

**评估协议：**
- 主要指标为闭环任务成功率（SR）。
- 所有模型从同一预训练 π0.5 检查点初始化，在相同任务数据上使用共享优化配方完全微调，数据流水线、动作表示、学习率调度和训练预算匹配。
- 随机种子在训练和评估前固定，同一基准内所有模型复用相同种子计划以控制场景初始化、物体实例/位置等环境随机性。
- 使用配对任务 bootstrap 计算95%置信区间；接口×深度扫描属于探索性分析，未做多重性校正。

## 6. 论文的主要结论与发现

**RQ1：当前状态是否改善闭环控制？**
- 总体上是有益的：无状态基线在原子任务上宏观成功率为54.6%，所有五个状态接口的点估计均超过该基线（+1.1~+3.1点）。
- 唯一获得置信区间支持的是离散状态提示（sp，57.7%，95%区间[0.2,6.1]），其余接口的增益可视为一致的正向趋势而非单独成立的效应。
- **没有任务无关的最佳接口**：家族A（重排列）中sp最优（68.7%，+7.0）；家族B（关节物体交互）中vp最优（68.8%，+6.1），se/fm紧随其后；家族C（旋钮/开关）中se最优（42.8%，+3.3），vp反而低于基线（-1.2）。单一平均指标会掩盖这些反向排名。
- 计算成本差异巨大：sp最昂贵（训练约1114 GFLOPs/样本），se/fm以极小边际成本达到相近宏观点估计（57.6%），存在显著性能-效率权衡。

**RQ2：状态历史是否有用，需要多长？**
- 历史深度对原子任务的影响呈**非单调**趋势：短历史（约8帧）提升超过单帧模型，深历史（≥32帧）不再带来额外收益，甚至会降低性能，尤其在家族C上明显退化。
- 8帧历史被选为默认操作点，兼顾时间信息与上下文冗余。
- 复合任务上，从单帧扩展到8帧提高了多数接口的性能，其中动作侧（ap）收益最大（+10.8点），VLM侧（vp）反而不稳定（-0.6点）。
- **slot-matched对照**（8帧真实历史 vs 8份重复当前帧）表明：增益来自真实的时序变化而非额外token容量；配对bootstrap区间排除零（+8.2点差异）。
- 该结论在关节角度状态表示下同样成立，说明益处不依赖于特定坐标系。

**RQ3：状态应注入何处？**
- **单帧（K=1）时优先VLM侧**：在复合任务上，vp1显著优于ap1（34.4% vs 28.2%，EEF状态；33.6% vs 31.4%，关节角度），且是唯一明确超过无状态基线（28.4%）的接口。
- **短历史（K=8）时优先动作侧**：ap8在所有面板中取得最佳成绩（原子59.6%、复合39.0%），而vp8基本无增益甚至略降。
- 得出设计规则：**单帧状态注入VLM前缀，多帧状态历史直接馈送到动作头**。
- 探针实验支持该数据流解释：VLM侧状态显著改变多模态上下文（语言-图像注意力重分配达17.3%~22.0%），动作侧状态则在动作专家内部直接作用；ap从K=1到K=8使状态校正与专家残差方向对齐从0.079升至0.270。
- 此规则为方向性模式而非严格机制证明：关节角度下两条路径在K=8收敛（36.2% vs 35.8%），且多数比较为单种子点估计。

## 7. 优点

- **高度受控的实验范式**：在同一测试平台（π0.5）上，固定骨干、数据、动作表示和评估协议，使界面比较干净可归因，避免了以往文献中系统间混杂无法比较的问题。
- **三维设计空间分解**：将“状态如何使用”清晰拆分为表示形式、时间深度和注入位置三个轴，每个轴有独立可验证的问题。
- **严格的对照组**：引入“重复当前状态”的slot-matched控制，有效区分了真实时序信息与额外条件token容量，这是历史深度研究中的关键方法贡献。
- **任务家族预设而非后果分组**：按操控语义预先划分任务家族，避免事后选择偏倚，并揭示接口-任务匹配的复杂交互。
- **多粒度证据**：宏观成功率 + 家族级分析 + 配对bootstrap区间 + 固定检查点探针（数据流追踪）+ 单任务案例研究（PrepareToast），形成了从系统级到机制级的多层证据链。
- **计算成本透明化**：解析推导边际训练/推理开销，提供独立于硬件的资源评估框架，使性能-效率权衡成为可讨论的设计维度。
- **可复用的评估协议**：论文的接口定义、对比协议、配对方法和案例研究方案可直接用于未来状态感知VLA的审计和基准测试。

## 8. 不足与局限

- **缺乏真实机器人验证**：所有实验均在RoboCasa365仿真环境中完成，仿真与真实间的差距可能影响结论向实物平台迁移的有效性。
- **状态模态局限**：仅研究了纯运动学状态（位姿、关节角度、夹爪位置），未涵盖力/力矩、触觉等模态；结论无法推广到更丰富的本体感觉维度。
- **统计效力有限**：多数结果为单种子点估计，不做多重性校正；仅sp的宏观增益有区间支持，其余界面的正向收益仅为趋势；ap/vp在关节角度、K=8时差异处于bootstrap噪声带内，路由规则是方向性而非强统计结论。
- **接口并非完全容量匹配**：se/fm参数规模远大于其他接口，且训练样本暴露略低（硬件原因）；因此界面对比衡量的是“完整系统”而非纯粹的注入位置变量。
- **单一大规模预训练基座**：所有实验基于π0.5单一模型，未验证结论在GPT-4V类VLM、不同规模或不同动作表示下的普适性。
- **探索性深度扫描**：1~96帧的深度扫描未针对多重比较校正，部分深度配置的结论可能受随机性影响。
- **复合任务分布内性**：Phase 2仅评估新episode，不涉及未见任务语义的泛化，因此对“历史状态是否帮助新任务泛化”的问题未做回答。
- **状态中基座位姿的语义混杂**：作者承认基座位姿携带世界坐标系定位信息，不能纯粹视为“内部运动反馈”，可能影响对本体感觉机制的解释。
