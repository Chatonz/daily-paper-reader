## 摘要
主流世界-动作模型（WAMs）将预训练视频生成模型（VGMs）适配到机器人控制，将其学到的动力学先验迁移到动作预测中。这些VGMs通常在变分自编码器（VAE）潜空间中训练。然而，VAE潜空间是针对像素重建优化的，这重视精细的外观细节，但使得动作预测在视觉变化下变得脆弱。近期工作在语义潜空间中构建WAMs，这对外观变化更具鲁棒性。然而，这些模型无法利用仅在VAE空间中可用的大规模VGM预训练。为了克服这一困境，我们提出Robust-WAM，一种针对基于视频生成的WAMs的通用后训练方法，它保留基于VAE的生成路径，并在动作流上添加轻量级的语义预见对齐目标。这保留了大规模VGM预训练，同时将动作锚定在对外观不变且光照变化及其他视觉分布外条件下依然可靠的动力学中。具体而言，我们采用可学习的查询令牌，将其输出隐藏状态与未来真实帧的语义预见对齐，从而将未来场景语义引入动作流。为了在每个查询与其描述的未来步骤之间建立时间对应关系，我们为其提供匹配动作令牌的位置编码。在分布外泛化模拟基准和真实机器人设置上的实验表明，我们的Robust-WAM持续提高了多个WAM基线的成功率，且不牺牲分布内性能。

## Abstract
Mainstream World-Action Models (WAMs) adapt pretrained video generation models (VGMs) for robot control, transferring their learned dynamics prior for action prediction. These VGMs are typically trained in a variational autoencoder (VAE) latent space. However, the VAE latent space is optimized for pixel reconstruction, which rewards fine appearance detail and leaves the action prediction fragile under visual shifts. Recent works build WAMs in semantic latent space, which are more robust to appearance shifts. However, these models cannot leverage the large-scale VGM pretraining that exists only in VAE space. To overcome this dilemma, we propose Robust-WAM, a general post-training method for video-generation-based WAMs that preserves the VAE-based generative path and adds a lightweight semantic foresight alignment objective on the action stream. This retains the large-scale VGM pretraining while grounding actions in appearance-invariant dynamics that stay reliable under illumination shifts and other visual out-of-distribution conditions. Specifically, we employ learnable query tokens to bring future-scene semantics into the action stream by aligning their output hidden states with the semantic foresight of future ground-truth frames. To establish the temporal correspondence between each query and the future step it describes, we give it the positional encoding of the matching action tokens. Experiments on out-of-distribution generalization simulation benchmarks and a real-robot setup show that our Robust-WAM consistently improves the success rates of multiple WAM baselines without sacrificing in-distribution performance.

## 1. 论文的核心问题与整体含义

- **研究背景**：世界-动作模型（World-Action Models, WAMs）通过耦合预训练视频生成模型（VGMs）来为机器人操作提供动力学先验。这些 VGMs 通常在 VAE 潜空间中训练，该空间优化目标是像素重建，保留了大量外观细节（如纹理、光照），导致动作预测在面对视觉分布外（OOD）变化（如光照、色调改变）时十分脆弱。
- **核心矛盾**：存在一个两难问题：
  - VAE 潜空间的 WAMs 能继承大规模视频生成预训练的动力学先验，但对外观变化脆弱；
  - 语义潜空间的 WAMs（如基于 DINO 或 V-JEPA）对外观变化鲁棒，但无法利用仅在 VAE 空间中存在的大规模 VGM 预训练，需要昂贵的重新预训练。
- **本文目标**：提出一种通用后训练方法 `Robust-WAM`，在不丢弃 VAE 生成路径和预训练动力学先验的前提下，将语义预见注入动作流，从而同时获得“继承 VGM 预训练”和“对视觉 OOD 鲁棒”的能力。
- **整体含义**：改变了以往“要么换潜空间、要么放弃预训练”的二元选择，表明生成式预训练与视觉鲁棒性可以兼得，为视频生成型 WAM 的鲁棒性提升提供了一种即插即用的范式。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 保留原始 WAM 的 VAE 视频分支和原有视频生成损失，不修改其 tokenization、denoising 路径和视频-动作注意力结构。
- 在动作流上添加 **轻量级语义预见对齐目标**：通过可学习查询 token 将未来帧的 DINOv3 CLS 语义特征“拉入”动作生成过程，使动作流具备外观不变的前瞻语义信息。
- 训练时使用冻结的 DINOv3 作为教师提供对齐目标；推理时丢弃教师和线性对齐头，只保留查询 token，不增加额外推理成本。

### 2.2 关键技术细节

#### 基础形式：WAM 双流联合去噪
- 输入：当前观测 \( o_t \)、语言指令 \( \ell \)，未来帧 VAE 潜变量 \( x = E(o_{t+\Delta}, \dots, o_{t+T_f\Delta}) \)，动作块 \( a = a_{t:t+H-1} \)。
- 视频流损失（flow matching）：
  \[
  \mathcal{L}_{\text{video}} = \mathbb{E}\left[ \| v^v_\theta(x_s, s | o_t, \ell) - (\epsilon - x) \|^2 \right]
  \]
- 动作流损失：
  \[
  \mathcal{L}_{\text{act}} = \mathbb{E}\left[ \| v^a_\theta(a_s, s | H_v, o_t, \ell) - (\epsilon' - a) \|^2 \right]
  \]
- 总损失：\( \mathcal{L}_{\text{WAM}} = \mathcal{L}_{\text{video}} + \lambda_a \mathcal{L}_{\text{act}} \)

#### 语义查询 token 设计
- 为每个未来帧和每个摄像头视图引入一个可学习查询 token：\( q \in \mathbb{R}^{K \times d} \)，其中 \( K = T_f \times C \)（\( T_f \) 为未来帧数，\( C \) 为相机数）。
- 查询 token 被前置到动作 token 序列：\( h = [q; h_a] \)。
- **时间位置编码映射**：查询 token 使用与其描述的未来帧所对应的动作步（\( \tau_j = \min(j\Delta, L) \)）的位置编码，从而建立查询-未来步的明确对应关系。动作 token 保留原有位置索引 1..L。
- 经动作 Transformer/专家处理后，查询输出通过一个线性头 \( g \) 映射到语义目标空间。

#### 语义对齐损失
- 目标：冻结的 DINOv3 ViT-B/16 CLS embedding，从未来真实帧中提取得到 \( z^* \in \mathbb{R}^{K \times d_z} \)（\( d_z = 768 \)）。
- 损失：
  \[
  \mathcal{L}_{\text{align}} = \frac{1}{K} \sum_{k=1}^K \left( 1 - \cos\big(g(\bar{h}_k), z^*_k\big) \right)
  \]
- 总训练目标：\( \mathcal{L} = \mathcal{L}_{\text{WAM}} + \lambda_{\text{align}} \mathcal{L}_{\text{align}} \)，其中 \( \lambda_{\text{align}} = 0.1 \)。

#### 架构兼容性
- **Action-Expert WAMs**（如 GE-Act、FastWAM、Motus）：查询 token 直接加到动作专家序列中，参与专家自注意力并对视频塔交叉注意力。
- **Unified WAMs**（如 LingBot-VA，基于 Wan2.2）：查询插入动作段，并继承对应动作 token 的序列、帧、噪声 ID，使其在 flex-attention 掩码下与同一步骤动作 token 双向交互、跨步骤保持自回归顺序。

## 6. 主要结论与发现

1. **Robust-WAM 稳定提升 OOD 泛化，且不损失 InD 性能**：
   - LIBERO-Plus：FastWAM + ours 从 49.7% → 58.9%（+9.2）；GE-Act + ours 从 78.0% → 80.9%（+2.9）。Clean LIBERO 分别 +0.3 和 +0.8，基本持平。
   - RoboTwin random：LingBot-VA + ours 从 29.8% → 34.4%（+4.6），clean 保持 81.2%。
   - 真实机器人：GE-Act + Robust-WAM 在 OOD 光照下平均成功率从 57.3% 提升到 80.0%，InD-OOD gap 从 22.7 降至 2.7。
2. **逐轴分析显示增益不限于光照**：FastWAM 在 sensor noise（+18.9）、camera（+12.4）、light（+11.3）、BG（+10.3）上增益最大；GE-Act 在六/七个扰动轴均有提升。
3. **语义先验增强优于替代**：LDA-1B（纯语义潜空间、无大规模 VGM 预训练）在 LIBERO-Plus 仅 45.5%，远低于 GE-Act+ours（80.9%）；在 RoboTwin random 仅 12.3%，低于 LingBot-VA+ours（34.4%）。说明语义信息应作为增强而非替代大规模生成先验。
4. **消融验证设计有效性**：
   - DINOv3 CLS 目标优于 Patch tokens、深度特征和组合特征；
   - 时间位置编码（future-step indexing）和未来帧语义目标（而非当前帧）都是必要的。

## 7. 优点

- **方法设计优雅**：不替换潜空间、不修改视频生成路径，仅增加轻量语义对齐目标，保持了 WAM 原有的大规模预训练收益，且训练后推理零额外成本。
- **即插即用**：适用于 action-expert 和 unified 两种主流 WAM 架构，实验证明对多种基线（FastWAM、GE-Act、LingBot-VA）均有效。
- **时间对应关系清晰**：通过共享动作位置编码将查询与未来步显式绑定，优于先前未显式建模时间对齐的表示对齐方法。
- **实验验证充分**：模拟 OOD 覆盖多扰动轴，真实机器人验证光照 OOD，且消融实验完整，直接支撑了核心设计决策。
- **意义明确**：提出了一个新的视角——用增强的方式融合语义先验和生成先验，而不是二选一，为后续 WAM 鲁棒性研究提供了可行路径。
