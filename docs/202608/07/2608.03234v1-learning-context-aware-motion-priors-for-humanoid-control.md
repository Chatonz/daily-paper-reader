## 摘要
运动先验为学习自然的人形行为提供了强有力的指导。然而，现有方法通常从整个参考数据集中学习一个通用的、与任务无关的先验，并在策略训练过程中统一应用。因此，该先验无法区分哪些参考运动与当前任务上下文相关，可能提供不相关或冲突的指导。我们提出了上下文感知运动先验（CMP），这是一个无需手动技能标签、数据集划分或单独技能发现阶段即可将通用运动先验适应到当前任务上下文的框架。具体来说，CMP利用高优势策略回滚来学习上下文-运动兼容性，同时基于演示的目标使学习到的相关性保持在参考分布中。所得的相关性分数对训练轻量级上下文条件适配器的参考监督进行重新加权。为了评估CMP的有效性和通用性，我们将其与对抗运动先验和分数匹配运动先验相结合。在五个人形控制任务中，CMP一致地提高了任务性能和样本效率，学习了有意义的上下文-运动对齐，并且对不平衡的参考分布保持稳健。这些结果表明，将运动先验适应到任务上下文为人形策略学习提供了更相关的指导。

## Abstract
Motion priors provide powerful guidance for learning naturalistic humanoid behaviors. However, existing methods typically learn a general, task-agnostic prior from the entire reference dataset and apply it uniformly throughout policy training. As a result, the prior cannot distinguish which reference motions are relevant to the current task context, potentially providing irrelevant or conflicting guidance. We present Context-Aware Motion Priors (CMP), a framework that adapts a general motion prior to the current task context without manual skill labels, dataset partitioning, or a separate skill discovery stage. Specifically, CMP learns context-motion compatibility using high-advantage policy rollouts, while a demonstration-based objective keeps the learned relevance grounded in the reference distribution. The resulting relevance scores reweight reference supervision for training a lightweight context-conditioned adapter. To evaluate the effectiveness and generality of CMP, we instantiate it with both Adversarial Motion Priors and Score-Matching Motion Priors. Across five humanoid control tasks, CMP consistently improves task performance and sample efficiency, learns meaningful context-motion alignment, and remains robust to imbalanced reference distributions. These results show that adapting motion priors to task contexts provides more relevant guidance for humanoid policy learning.

- **研究问题**：能否让通用运动先验**在线适应当前任务上下文**，直接在原始参考空间中工作，而无需技能标签、数据集划分或独立的技能发现阶段？

## 二、方法论：Context-Aware Motion Priors (CMP)

### 2.1 核心思想

- CMP 是一个**模块化框架**，在任务无关的基础运动先验之上，学习上下文与参考运动之间的兼容性函数，并用学到的相关性分数对参考分布进行**软重加权**，训练一个轻量级上下文条件残差适配器。
- 核心分离：**通用运动合理性**由基础先验负责，**上下文相关的任务相关性**由适配器负责。

### 2.2 重加权视角

- 定义相关性函数 $R_\phi(c, x): \mathcal{C} \times \mathcal{X} \to \mathbb{R}$，其中 $c$ 为任务上下文，$x$ 为参考运动序列。
- 重要性权重：
  $$w_\phi(c, x) = \frac{\exp(\alpha R_\phi(c, x))}{\mathbb{E}_{x' \sim p_E}[\exp(\alpha R_\phi(c, x'))]}$$
- 有效上下文条件参考分布：$q_\phi(x|c) = w_\phi(c,x) p_E(x)$，即对当前上下文更兼容的运动赋予更高重要性。
- 实践中采用**小批量近似**，权重裁剪到 $[w_{\min}, w_{\max}]$（实验中为 [0.5, 2.0]）以稳定训练。
- 适配器损失：$L_{\text{adapt}}(\psi) = \mathbb{E}_{c \sim d^\pi, x \sim p_E}[\text{sg}[\bar{w}_\phi(c,x)] \ell_{\text{adapt}}^\psi(c,x;\theta)]$，梯度不反向传播到相关性模型 $\phi$ 或基础先验 $\theta$。

### 2.3 对比相关性学习（双重分支）

- **在线任务相关性分支（$L_{\text{on}}$）**：从策略 rollout 中提取标准化 GAE（优势估计），选取高优势样本（$\hat{A}_i > 0$）作为正样本锚点，用量 $A_i$ 加权；优势越大，该运动与上下文的匹配信号越强。公式为对比损失形式，批次内其他运动作为负样本。
- **演示正样本分支（$L_{\text{demo}}$）**：由于在线探索可能无法覆盖参考数据集中的全部行为，该分支将参考运动作为正样本、rollout 运动作为负样本，将上下文表示**锚定在参考数据分布的支持域内**，避免上下文嵌入漂移。
- 最终目标：$L_{\text{rel}}(\phi) = L_{\text{on}}(\phi) + \lambda_{\text{demo}} L_{\text{demo}}(\phi)$。

### 2.4 与具体运动先验的集成

- **CMP-AMP（主要实例化）**：
  - 上下文条件 logit：$l_{\theta,\psi}(c,x) = \text{sg}[l_\theta(x)] + \lambda_{\text{res}} \Delta l_\psi(c,x)$
  - 参考侧使用相关性加权二分类损失，策略侧保持未加权负项；基础判别器仍按原始 AMP 目标训练。
- **CMP-SMP（扩展实例化）**：
  - 上下文条件噪声预测：$\hat{\epsilon}_{\theta,\psi}(c, \tilde{x}_t, t) = \text{sg}[\epsilon_\theta(\tilde{x}_t, t)] + \lambda_{\text{res}} \Delta\epsilon_\psi(c, \tilde{x}_t, t)$
  - 加权去噪损失 + 残差正则化，预训练去噪器保持冻结。

## 六、主要结论与发现

1. **一致性的性能提升**：CMP-AMP 在全部5个任务上回报优于 AMP，在4个任务上样本效率更高（Steering 持平）；CMP-SMP 也有一致但幅度较小的增益。
2. **有意义的上下文-运动对齐**：学习到的相关性权重随训练演化——早期均衡偏向行走，后期近目标偏好长走、远目标偏好快跑、侧向/背向目标偏好转向跑，说明模型学到了行为与空间任务需求的匹配。
3. **演示分支的关键作用**：去掉 $L_{\text{demo}}$ 后，上下文嵌入漂移出参考分布支持域（PCA投影出现离群点），检索出的运动不恰当；完整 CMP 能检索到走、跑、刹车等合适动作。
4. **消融验证组件贡献**：Uniform Adapter（仅架构增益）和 Shuffled Relevance（破坏上下文-运动对应）均无法同时保证性能与效率；Online Branch Only 虽可达竞争性最终回报但样本效率更低——说明**有意义的对应关系**和**演示支持**都很重要。
5. **对不平衡分布鲁棒**：行走运动重复 ×100 时，AMP 回报下降 11.5%，CMP-AMP 仅下降 2.8%（454 vs 361），表明上下文感知重加权降低了先验对主导频率的敏感性。

## 七、方法亮点

- **通用且即插即用**：不修改基础先验，只加轻量适配器；可同时实例化到对抗式（AMP）和分数匹配式（SMP）两类主流先验。
- **无监督要求**：无需技能标签、数据集划分或独立技能发现阶段，全部从策略在线经验中学习。
- **模块化解耦**：通用运动合理性（基础先验）与上下文任务相关性（适配器）分离，概念清晰。
- **双重对比分支设计巧妙**：高优势 rollout 提供任务相关性信号，演示正样本分支防止表示漂移，两者互补。
- **抗分布不平衡**：软重加权机制天然降低参考数据高频模式的影响。
- **可解释性**：相关性权重热力图和运动检索分析使学习到的对齐直观可验证。

## 八、不足与局限
