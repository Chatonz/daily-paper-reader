## 摘要
我们提出了DreamX-Phi 1.0，一个用于机器人操作的动作条件视频世界模型，该模型给定一个观察帧、一条语言指令以及一个包含末端执行器姿态和夹爪状态的规定动作序列，预测由此产生的未来观察。然而，仅凭真实性并不能保证保真度：一个令人信服的展开仍可能移动错误的手臂或丢失被操作物体。为了确保预测尊重每只手臂的命令路径，我们通过PRoPE风格的几何编码将每只手臂的SE(3)变换注入注意力机制中，从而保持手臂身份和刚体运动结构。仅靠动作控制并不能完全约束场景几何或小操作物体的演变。因此，我们添加了一个轻量级深度分支用于场景级几何，并使用冻结的V-JEPA教师通过SAM3掩码在抓取过程中维持物体一致性。我们进一步通过分布匹配蒸馏将多步生成器蒸馏为少步学生模型，以实现高效部署。在撰写本文时，我们的模型在WorldArena 2.0挑战赛的Track 1中排名第一，在Track 2中排名第二。我们的模型和代码将公开发布。

## Abstract
We present \textbf{DreamX-Phi 1.0}, an action-conditioned video world model for robotic manipulation that, given an observed frame, a language instruction, and a prescribed action sequence comprising end-effector poses and gripper states, predicts the resulting future observations. Yet realism alone does not guarantee faithfulness: a convincing rollout can still move the wrong arm or lose the manipulated object. To ensure the prediction respects each arm's commanded path, we inject per-arm $\mathrm{SE}(3)$ transformations into attention via \textbf{PRoPE-style geometric encoding}, preserving arm identity and rigid-motion structure. Action control alone does not fully constrain scene geometry or the evolution of small manipulated objects. We therefore add a lightweight \textbf{depth branch} for scene-level geometry and use \textbf{SAM3 masks} with a frozen \textbf{V-JEPA teacher} to maintain object consistency throughout grasping. We further distill the multi-step generator into a few-step student via distribution-matching distillation for efficient deployment. At the time of writing, \model{} achieves first place on Track~1 and second place on Track~2 of the WorldArena~2.0 Challenge. Our model and code will be publicly available.

### 1. 核心问题与研究动机

- **问题背景**：视频生成模型（如 Wan、Cosmos 等）具备强大的视觉先验，能够生成高度逼真的未来帧。然而，**"逼真"不等于"忠实"**——一个视觉上令人信服的展开可能移动了错误的手臂、丢失了被操作物体，或误解了抓取与释放动作。
- **核心挑战**：
  - 现有方法（如 IRASim、Vid2World 等）将动作编码为紧凑 token 或特征调制，但这些表示**不保留末端执行器运动的刚体几何结构**，也无法明确指出动作应在图像中哪里产生效果。
  - 仅约束机器人动作不能完全约束场景几何和小的操作物体的动态演化。
- **研究目标**：构建一个动作条件视频世界模型，给定观察帧、语言指令和双机械臂动作序列，预测未来观察结果，并确保预测**严格遵循规定的每只手臂的运动路径**，同时保持场景几何和物体状态的一致性。

### 2. 方法论

DreamX-Phi 1.0 基于 Wan2.2-TI2V-5B 视频扩散 Transformer，在 flow-matching 目标下训练，整体框架包含三个核心部分：

- **PRoPE 控制（动作条件注入）**
  - 将每只手臂的 SE(3) 末端执行器轨迹（位置 + 四元数 + 夹爪状态）以残差分支形式注入注意力的 Q/K/V 变换中。
  - 所有手臂先转换到以手臂 1 初始姿态为基准的公共坐标系，并按运动幅度归一化平移量。
  - 每个 Transformer 块包含一个并行注意力分支，投影矩阵 \( P_{kt} = A_{kt} \)（单位内参矩阵下简化），对 token 施加 \( D_i \) 变换，使注意力权重的计算通过 **PRoPE 式近似位移**关联任意 token 对。
  - 夹爪状态为标量，无法作为 SE(3) 元素，因此以**每手臂注意力头偏置**的形式注入。
  - 该残差分支初始化为零，保证几何控制增强而非替代预训练生成能力，并保持手臂身份和刚体结构。

- **深度辅助监督（3D 一致性）**
  - 预训练 Video VAE 对深度图编码得到 latent 目标 \( z_d \)。
  - 复用 RGB Transformer 的最后 M 块作为辅助深度分支，使用**单向交叉注意力**（深度分支读取 RGB 特征，反向不传递），保持 RGB 前向计算不被修改，使深度预测在推理时可选。
  - 目标为 latent 空间 MSE：\( L_{depth} = \frac{1}{|z_d|}\|\hat{z}_d - z_d\|_2^2 \)。

- **物体中心物理一致性监督**
  - **SAM3 掩码加权 RGB 损失**：由 SAM3 离线生成的物体二值掩码对 flow-matching token 损失重新加权，提高接触局部区域损失的权重，解决小物体在全局生成目标中被背景淹没的问题。
  - **V-JEPA 关系对齐**：冻结的 V-JEPA 教师提取掩码区域特征，学生特征与教师特征在投影后计算 Gram 矩阵的 L1 距离（关系损失），约束物体身份和形状在接触时段内不漂移。仅在掩码 token 数量足够且噪声水平不太高时启用。
  - 两项目标互补：掩码加权确定"哪里"重要，V-JEPA 约束"如何"演变。

- **DMD 蒸馏后训练**
  - 使用 DMD2（分布匹配蒸馏 + 非饱和 GAN 对抗目标）将多步教师蒸馏为 N 步采样学生，训练时使用固定 N-step 去噪调度和 backward simulation，条件组 y（观察帧、动作轨迹、语言指令）在所有步骤中保持固定。

### 7. 优点

- **几何感知动作条件注入（PRoPE）**：不同于 token/feature 调制，显式保持 SE(3) 刚体轨迹结构并保留手臂身份，将"动作应在哪里产生效果"编码进注意力计算。
- **补充的多模态监督协同**：RGB 掩码加权损失的"哪里" + V-JEPA 的"如何演变" + 深度分支的几何线索，覆盖了物体感知、物理一致性和场景三维结构三个层面。
- **保留预训练能力**：PRoPE 作为残差分支零初始化、深度分支单向连接，确保辅助机制不破坏预训练生成路径。
- **实用友好**：SAM3、V-JEPA、VAE 均为冻结模型；推理时不要求掩码或深度输入；DMD 蒸馏支持少步高效推理，适合实际部署。
