## 摘要
长时间跨度的具身感知视觉-语言-动作（VLA）控制通常依赖头戴式立体相机，这要求视觉接口能够利用互补视图，同时保持与预训练表示的兼容性。现有接口往往舍弃互补的立体证据，或在未保留原生主视图通路、未将辅助信息适配至机器人具身形态的情况下，直接融合额外观察信息。我们提出EATR-Stereo，一种具身感知的令牌路由框架，该框架保留主视图令牌，并通过查询同步的辅助视图令牌序列，构建主视图对齐的跨视图辅助令牌（CVATs）。一种基于身体分割的本体感受编码器进一步根据机器人配置历史调节令牌级别的辅助使用，从而在动作生成过程中选择性融合立体证据。路由后的辅助流增强了预训练VLA的语言和主视图视觉上下文，同时其视觉-语言模型保持冻结。在一台具有33个自由度、37维本体感受状态的人形机器人上，我们在超过100秒的搜索-接近-抓取-放置-返回任务中评估了九种配置。EATR-Stereo实现了60.0%的全任务成功率、100.0%的抓取成功率和80.0%的阶段成功率。在严重不对称遮挡下，其恢复成功率提升至80%，而仅使用CVAT时为30%。消融研究进一步表明了保留主视图令牌以及将跨视图辅助特征与结构化本体感受路由相结合的重要性。这些结果表明，选择性路由的配对立体证据增强了空间接地能力，从而实现了可靠的长时程人形VLA控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

## 1. 核心问题与整体研究动机

- **问题背景**：长时程（>100 秒）人形机器人视觉-语言-动作（VLA）控制中，头戴式立体相机能够提供同步配对视图，具备互补可见性与双目视差线索，有利于在全身运动、自遮挡和视角变化条件下提供空间接地能力。
- **现有接口的不足**：
  - 单目（monocular）输入缺乏视差和遮挡下的备选视角；
  - 独立两图 token 拼接（concatenation）虽然保留两幅图像，但不显式建立跨视图空间关系；
  - StereoPolicy 虽显式关联视图，但其 VLA 变体用融合后的立体表示替换了预训练的单目 token 结构，破坏了原生主视图语义通路；
  - SpatialVLA 依赖单目深度估计（ZoeDepth），且在物理评估中使用静态或三脚架相机的机械臂平台，未覆盖头戴式双足感知场景（单目深度时序不一致、步态扰动相机）；
  - 现有视觉-本体感受融合方法未将配对视图的选择建立在身体语义状态（如头部、腰部、手臂姿态）之上，而人形机器人的自遮挡与视角高度依赖身体构型。
- **核心研究问题**：如何在保留预训练 VLA 的主视图原生通路的同时，将配对立体证据按机器人本体状态进行选择性地、具身感知地融合，从而提升长时程人形操控的可靠性与空间泛化能力。

## 2. 方法论：EATR-Stereo

**核心思想**：保留主视图 token 不变，通过交叉注意力从同步辅助视图查询得到主视图对齐的辅助 token 流（CVAT），并用身体分割的本体感受历史预测每个 token 级别的路由权重，选择性融合立体证据；整个视觉-语言模型（VLM）保持冻结。

**关键模块与流程**：

- **问题建模**：策略以当前时刻的同步立体图像对 \((I^L_t, I^R_t)\)、语言指令 \(\ell_t\)、以及最近 K 帧本体感受历史 \(S_t\) 为输入，预测 H 步连续动作块。设定左视图为主视图 \(I^p_t\)、右视图为辅助视图 \(I^a_t\)，指派固定不变。
- **Cross-View Auxiliary Token（CVAT）构建**：
  - 冻结的 Cosmos VLM 同时编码立体图像对与语言指令，分别得到语言 token 序列 \(L_t\)、主视图视觉 token \(M_t\) 和辅助视图 token \(A_t\)；
  - 为两个视觉序列添加可学习视图角色嵌入；
  - 采用多头交叉注意力（以主视图 token 为 Query，辅助视图 token 为 Key/Value），为每个主视图 token 聚合辅助视图信息，经拼接、投影与 FFN 残差块得到主视图索引对齐的 CVAT 序列 \(C_t\)。
- **具身感知路由（Embodiment-Aware Routing）**：
  - 将 37 维本体感受状态分为 5 组语义段：腿部、手臂、头部、腰部、整体位姿；
  - 每组经过 LayerNorm + 独立 MLP + 段类型嵌入得到段表示 \(z_{t,g}\)；
  - 通过注意力加权和平均池化融合得到共享的路由条件 \(h^s_t\)；
  - 对每个 token，将主视图 token、CVAT token、二者的绝对差、逐元素乘积与共享本体条件拼接，输入轻量路由 MLP，经 Sigmoid 输出 (0,1) 标量，对 CVAT token 进行逐 token 缩放；
  - 主视图 token 参与路由描述但不被修改。
- **VLA 集成与训练**：路由后的辅助 token 与语言 token、主视图 token 拼接成上下文，联合原始状态 \(S_t\) 输入 GR00T N1.7 的流匹配（flow-matching）动作专家；使用流匹配目标函数 \(L_{FM}\) 训练；CVAT 模块、段状态编码器、路由器与动作专家联合优化，VLM 冻结。
- **部署设计**：
  - 异步动作块预测 + 执行缓冲；
  - 本地三次 B 样条拼接（cubic B-spline）平滑动作块边界；
  - 外部 VLM 评估子任务完成状态，FSM 决定保留或切换子任务指令。

## 3. 实验设计

**物理人形平台任务**：
- 平台：33 自由度 HONOR Omega 1.0，37 维状态（33 关节 + 4 维基座朝向四元数），头戴同步立体相机输出 240×320 图像；
- 任务：超过 100 秒的"搜索—接近—抓取—放置—返回"长时程任务，语言指令指定放置目标篮颜色/方位；

- 严重非对称遮挡测试：手部在主视图中完全遮挡瓶子、辅助视图中部分可见，各方法测 10 次，90 秒超时。

**仿真基准（RoboCasa365）**：
- 18 个任务、Franka 机械臂、共 3600 次 rollout（每方法每任务 20 次），排除腕部相机，仅保留左右代理视图；
- 额外加入 QwenPI0.5 作为外部 VLA 基线。

**对比方法**：
- GR00T1.7-Mono（单目）、GR00T-Wide（宽宽比双图拼接）、GR00T（默认双图 token 拼接）、StereoPolicy（融合立体表示替换主视图）；
- 消融变体：Main-XAttn（主视图经交叉注意力被修改）、CVAT（保留主视图 + 辅助流）、CVAT-Flat（扁平本体编码）、Stereo-Route（用 StereoPolicy 融合方案替换 CVAT）、EATR-Stereo（完整方法）。

**指标**：全任务成功率（主指标）、抓取成功率、阶段成功率（抓取与全任务的平均）、ID/OOD 阶段成功率、语义合规率（左右/颜色指令）、遮挡恢复率与平均恢复时间。

## 6. 主要结论与发现

- **主结果**：EATR-Stereo 在物理人形平台上实现 60.0% 全任务成功率、100.0% 抓取成功率、80.0% 阶段成功率，全面超越所有基线（比 StereoPolicy 高 15pp、比 GR00T 高 25pp、比 GR00T-Wide 高 40pp）；
- **OOD 泛化**：在未覆盖位置保持 100% 抓取率、70% 阶段成功率，20pp 优于 StereoPolicy；ID-OOD 差距为零；
- **遮挡恢复**：严重非对称遮挡下恢复率 80%（CVAT 仅 30%、CVAT-Flat 60%），平均恢复时间 22.4 秒，显著低于对照；
- **消融发现**：保留主视图通路（Main-XAttn → CVAT）带来 +30pp 全任务成功率提升；分段本体感受编码在扁平编码之上进一步提升抓取和阶段成功率；Stereo-Route 与完整方法对比证明 CVAT + 分段路由的组合优势；
- **效率发现**：在相同阶段成功率（80.0%）下，训练开销仅为 Estimated-Depth VLA 的约 1/4；
- **语言行为保持**：左右指令合规率 100%、颜色指令合规率 80%，与方法组中最佳水平持平的同时取得更高的空间泛化能力。

## 7. 方法优点

- **设计简洁且高效**：不修改预训练 VLM，通过轻量接口（CVAT + 路由）将立体证据融入现有 VLA 系统，训练开销仅增加 5.8%，部署可行性高；
- **保留主视图语义通路**：主视图 token 原样传递至动作专家，避免微调或重构预训练表示带来的语义漂移；
- **真正的具身感知路由**：将身体分段状态（腿/臂/头/腰/位姿）作为路由条件，实现对"哪部分辅助视觉信息在当前身体构型下有用"的自适应判断，而非静态融合；
- **跨视图对齐的明确建模**：以主视图 token 为 Query 从辅助视图查询信息，建立主视图索引对齐的辅助流，token 级别一一对应，利于细粒度路由；
- **部署工程考虑完整**：异步缓冲、B 样条边界拼接、外部 VLM 子任务 FSM 均为长时程实体任务的实际运行提供保障；
- **实验严谨性**：九个配置在同一骨干、相同演示数据与训练条件下比较，消融设计能清晰分离各组件贡献。

## 8. 不足与局限

- **平台单一性**：物理实验仅在一台特定人形平台上（HONOR Omega 1.0）完成，方法对其他人形平台或更广泛实施例的迁移性尚需验证；
- **物理样本量有限**：每方法 20 次物理试验的统计功效有限，较大差异置信度较好，但中等幅度差异（如 CVAT 与 CVAT-Flat 在全任务上的并列）难以分辨；
- **语言合规薄弱环节**：颜色指令合规率 80%，仍有 20% 失败空间，说明语言条件与视觉空间信息的结合仍不完全可靠；
- **未与最新多模态深度估计方法在物理平台展开同条件对比**：Estimated-Depth VLA 仅在成本对比中出现，未详细报告其在物理任务上的完整行为；
- **依赖外部 VLM 进行子任务完成判定**：FSM 切换依赖外部模型，可能会引入额外误差源，文中未深入分析该外部模型误判对整体成功率的影响；
- **未建模深度不确定性与显式置信度**：作者在结论中也承认，校准的不确定性建模和显式深度表示是未来方向；
- **GR00T-Wide 的性能劣势可能混杂了宽宽比图像与预训练裁剪策略不匹配的因素**，而不完全反映"双图拼接"策略本身的缺陷。
