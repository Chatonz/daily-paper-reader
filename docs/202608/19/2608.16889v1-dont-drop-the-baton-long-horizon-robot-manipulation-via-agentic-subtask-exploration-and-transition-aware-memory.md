## 摘要
长时程机器人操作将许多需要接触的技能串联成一个多阶段任务。视觉-语言-动作（VLA）模型日益擅长单个技能，但整个链条仍然会失败：错误累积超出了策略的纠正能力，且一个子任务会悄然限制下一个子任务。一种有前景的方案是冻结VLA，并由一个LLM智能体负责：它以语言进行规划，利用解析式基本动作在自由空间中移动，仅在需要接触的阶段调用VLA，并将适应性调整写入语言记忆。将该方案应用于长时程任务时，它会在两方面失效。（1）能力来自于测试时的全任务探索，其代价随阶段数呈乘法增长：若一个阶段需要T次尝试，则K阶段任务约需T^K次尝试，而一次失败并不能揭示是由哪个阶段导致的。（2）它缺乏对过渡状态的表示：VLA基本动作带有退出条件但没有进入条件，因此一个子任务可能以一种后续子任务无法使用的方式成功。我们提出BATON。针对（1），BATON将子任务作为探索的基本单元：每个子任务都在廉价的短时程场景中被探索，其解决方案存储在记忆中；随后，长时程轨迹由这些解决方案组合而成，而非整体发现。代价变为加法（T*K），且每次失败都能被归因到单一阶段。针对（2），BATON为探索配备了过渡感知记忆。在子任务内部，一个验证器智能体管理调用过渡：只有在腕部视图确认场景就绪后才会调用VLA。在子任务之间，交接过渡会恢复被前序子任务残留物干扰的进入状态，而前瞻过渡则选择其结果能被后续子任务继承的策略。参数不做任何更新。在长时程基准RoboMemArena上，BATON相比当前最优方法将任务成功率提升了11.6%，累计成功率提升了14.9%。

## Abstract
Long-horizon robot manipulation chains many contact-rich skills into one multi-stage task. Vision-language-action (VLA) models increasingly master the individual skills, yet the chain still fails: errors compound beyond the policy's ability to correct, and one subtask silently constrains the next. A promising recipe freezes the VLA and puts an LLM agent in charge: it plans in language, moves in free space with analytic primitives, invokes the VLA only for contact-rich segments, and writes adaptation into language memory. Applied to long horizons, it breaks twice. (1) Competence comes from whole-task exploration at test time, whose cost is multiplicative in stages: if one stage needs T episodes, a K-stage task needs about T^K, and a failure does not reveal which stage caused it. (2) It has no representation of transitions: the VLA primitive carries an exit but no entry condition, so a subtask can succeed in a form its successor cannot use. We present BATON. Against (1), BATON makes the subtask the unit of exploration: each is explored in the cheap short-horizon regime and its solution stored in memory; a long-horizon trajectory is then composed from these solutions rather than discovered whole. Cost becomes additive (T*K) and every failure is attributed to a single stage. Against (2), BATON equips exploration with a transition-aware memory. Within a subtask, a verifier agent governs the invocation transition: the VLA is called only after the wrist view confirms the scene is ready. Across subtasks, a handoff transition restores an entry state disturbed by the predecessor's residue, and a lookahead transition selects the strategy whose outcome the successor can inherit. No parameters are updated. On the long-horizon benchmark RoboMemArena, BATON improves task success by 11.6% and cumulative success by 14.9% over the SoTA.

## 一、核心问题与研究动机

### 1.1 研究背景

- 长时程机器人操作要求将多个**接触丰富的技能**（如开门、抓取、放置等）串联成一个**多阶段任务**，整体链条可达**上千控制步**。
- 现有的视觉-语言-动作（VLA）模型和世界-动作模型（WAMs）通过大规模预训练，已能在**单技能**任务上表现出色（如 π0.5 在单个子任务上可以干净地学习和执行）。
- 然而，当把这些技能**串联成链**时，系统表现急剧下降：例如 π0.5 能完成约一半的中间阶段，却只能完成 **约 10% 的完整长时程任务**——"阶段成功了，但任务在执行之间死掉了"。

### 1.2 核心问题：为什么"链条"会失败？

论文指出两种根本性障碍：

1. **障碍 ❶：全任务探索的指数级成本**
   - 编码智能体（coding agent）通过**测试时探索**获取能力，在整任务上反复试错直到首次成功。
   - 若单一阶段平均需 T 次探索才能成功，则 K 阶段串联任务的整任务探索需要约 **T^K 量级**的 episodes——超出任何可行预算。
   - 更糟的是，失败的 episode **无法定位是哪个阶段出了问题**，探索是"盲"的；且无法将部分成果存入记忆，前序阶段成功再多次也留不下任何可复用信息。

2. **障碍 ❷：缺乏对过渡（transition）的表示**
   - VLA 原语带有**退出条件（stop predicate）**，但没有**进入条件（entry condition）**，导致在场景未就绪时过早调用 VLA，使其从训练分布之外的状态开始执行。
   - 子任务之间通过状态耦合：前序子任务的**残留状态**（如抓手的朝向、位置）会破坏后续子任务所需的干净初始状态，但现有系统无法区分"技能本身不行"与"进入状态不对"。
   - 即使进入状态正确，一个**本地成功**的子任务可能以某种**后继子任务无法继承的形态**完成（如抓取方式导致无法放入微波炉），而探索阶段完全不会考虑这种跨子任务的约束。

### 1.3 现有方法的不足

- 端到端 VLA 过拟合演示数据的初始状态，无法纠正累积漂移（covariate shift），也无法感知跨子任务的执行耦合。
- 记忆增强型 VLA 将历史经验编码进策略参数，但记录的是"看到了什么"而非"选择了什么策略"，无法处理"同一条指令在不同后继条件下需要不同策略"的需求。
- 已有的边界修复方法（如 HANDFUL、Foresight Residual RL）每个技能配对都要付出一次性的训练成本，且将经验绑定在**固定后继策略**上，无法跨任务复用。

## 二、方法论：BATON

### 2.1 总体架构

BATON（**B**aton for **A**gentic subtask exploration and **T**ransition-aware mem**O**ry for lo**N**g-horizon manipulation）是一个 LLM 编码智能体，**冻结** VLA 作为唯一的接触型策略后端，通过分层探索和过渡感知记忆实现长时程操作，**全程不更新任何网络参数**。

系统结构采用分角色设计（均由同一 LLM agent 扮演）：
- **Explorer（探索者）**：负责子任务探索、试错、将解决方案写入记忆
- **Verifier（验证器）**：基于腕部相机图像验证场景就绪条件，控制 VLA 调用时机并修复交接处状态
- **Scheduler（调度器）**：在执行前读取剩余计划，选择能被后续子任务继承的执行策略

### 2.2 核心思想 1：分层子任务探索（Hierarchical Subtask Exploration）

**任务分解**：

将长时程任务分解为：

```
T = u₁ ▷ σ₁,₂ ▷ u₂ ▷ σ₂,₃ ▷ ... ▷ σ₍K₋₁,K₎ ▷ u_K
```

其中每个 uₖ 是一个短时程接触技能，每个 σₖ,ₖ₊₁ 是子任务间的交接边界（handoff boundary）。

**逐子任务探索**：

- 每个子任务独立地在**廉价的短时程范围**内探索，通过"试错—失败记忆—再尝试"的循环，直到首次成功。
- 首次成功的轨迹被抽象成**粗粒度轨迹**（coarse trajectory）写入技能记忆，包括：预接触位姿、VLA 调用条件、终止检查条件等。
- 所有失败的尝试写入**失败记忆**，避免后续重复同样的错误。

**逐层向外组合**：

- 已解决的相邻子任务下层配对验证（如"打开上抽屉→关上抽屉"），配对的成功单位再与相邻单位组合，逐层向外直到整条链端到端跑通。
- 组合过程中**不需要学习新技能**：直接按顺序执行已验证的单元。只有组成失败时（即边界出现问题），才会写入新的过渡记忆条目。
- 关键效果：探索成本从 T^K（指数）降为 **T·K + 每边界一次检查**（加法）。

### 2.3 核心思想 2：过渡感知记忆（Transition-Aware Memory）

论文将"过渡（transition）"视为一等公民，设类型：

**（a）调用过渡（Invocation Transition）——子任务内部**

将原本隐式的"从智能体到 VLA 的切换"显式化：

```
uₖ = aₖ ▷ σ_act_k ▷ vₖ
```

- σ_act_k 是一个**条件化门控**：只有腕部相机画面满足**就绪条件**（如"两个手指位于把手两侧"、"抓手两侧都在容器边缘内部"）时，才允许调用 VLA。
- 该条件由 **Verifier** 智能体从实时腕部图像零样本判断；失败则用解析原语重新布置场景，绝不强行通过门控。
- 收益双重：探索阶段不浪费 episode 去"发现"VLA 调用时机；执行阶段能拦截因累积漂移导致的错误前接触状态。

**（b）交接过渡（Handoff Transition）——跨子任务（前向）**

解决"前序子任务污染了后继子任务入口状态"的问题。

- 边界记录**入口条件（entry condition）**：后继技能开始前腕部视图必须满足的状态（如"抓手恢复竖直、张开状态并位于罐体上方"）。
- 边界执行时由 Verifier 检查并**用解析原语修复状态**（重新定向、重新张开、重新布置）。
- 入口条件是**边（edge）的属性**而非节点（node）的属性，因为"什么残留到达"由前序决定，"什么残留要紧"由后继决定。

**（c）前瞻过渡（Lookahead Transition）——跨子任务（后向）**

解决"当前技能成功但形态不被后继接受"的问题。

- 边界记录**执行约束（execution constraint）**：在给定后继计划 P>ₖ 的前提下，当前子任务必须以特定形态结束。
- 示例："拿起番茄罐"有侧握、顶部捏边、深握等**竞争策略**；放入微波炉只能用侧握（顶部握法加上抓手超过内腔高度），而长距离倾倒运输则需要深握。
- **Scheduler** 在 uₖ 执行前读取剩余计划，收集后继边界施加的约束，从记忆中选择满足约束的竞争策略，因此同一查询"拿起罐子"在不同后继下返回不同策略。
- 当现有策略都不满足新约束时，子任务带着新增约束回归 Explorer 重新探索。

**（d）统一记忆结构**

- **节点（node）**：子任务的失败条目 + 所有竞争策略的粗粒度轨迹，每个轨迹内嵌自身的调用过渡就绪条件。
- **边（edge）**：每对子任务边界的手控合同 Cₖ,ₖ₊₁ = 交接过渡入口条件 + 前瞻过渡执行约束。
- 关键设计：**竞争策略被保留而非合并**；边以**过渡类型**为键（而非以任务为键），因此可在任务间迁移（如"释放到窄唇容器"从篮子迁移到垃圾箱）；违反合同时将失败回写，约束对应策略。

### 2.4 核心技术公式与流程（文字版）

**整体分解**：先将长时程指令拆分成 K 个子任务和 K−1 个交接边界，参考既有记忆，可继承的不再重新探索。

**子任务引导循环**：对无可复用记忆条目的子任务，Explorer 在短时程范围内测试不同预接触姿势、布置顺序、VLA 调用时机（受腕部相机门控），失败写入失败记忆，首次成功固化为带条件的粗轨迹进入技能记忆。

**层级组合**：按"近邻配对→信任单元→单元再配对"的方式向外组合，每轮只检查新形成的边界，每个边界在其两侧首次相遇的那一轮**只检查一次**。

**执行读记忆**：测试阶段只读取技能记忆与过渡记忆。每个子任务前，Scheduler 读取剩余计划并选定策略；Verifier 在调用 VLA 前验证就绪条件；每个边界执行前，Verifier 验证并修复入口条件。

## 三、实验设计

### 3.1 基准与场景

- **Benchmark**：RoboMemArena——专为评估长程操纵记忆设计的基准。26 个家庭任务，平均超过 **1000 步**，每个任务含 3–9 个验证阶段，部分场景部分可观测，**68.9% 的子任务是记忆依赖型**。
- **任务类别**（4 类）：
  - **Transferring（4 个任务）**：视觉相似容器间的源-目标映射。
  - **Occlusion（11 个任务）**：物体位置/状态被遮挡或不可见。
  - **Counting（7 个任务）**：动作已执行次数影响后续决策。
  - **Sequence（4 个任务）**：前置子任务的结果决定下一个动作（基准形式中的"耦合问题"）。

### 3.2 实验协议

- **探索与评估分离**：每个任务的探索固定在单一参考场景配置（seed 50）；评估在另外两个保留配置（seed 51、52）上进行；报告数字为两次评估的平均值。
- **后端配置**：冻结 π0 系列 VLA（π0.5），由 LLM 编码智能体编排，沿用 Harness VLA 的配置。

### 3.3 对比方法

| 类型 | 方法 |
|---|---|
| 基准报告的方法 | GPT-5.4（仅 VLM 智能体）、π0.5（自主反应式 VLA）、HiF-VLA、MemoryVLA、MemER、PrediMem（有无 GT memory 两种）、FrameSamp+Modul |
| 作者自行运行 | **Harness VLA（未修改）**：在相同 seed 50 上对每个任务整体探索，预算为每任务 20 个 episodes，再在相同保留 seed 上评估 |

### 3.4 主要结果

- BATON 取得 **平均 TSR 57.7%、CSR 78.8%**，相比最强报告系统 FrameSamp+Modul（46.1/63.9）分别提升 **+11.6** 和 **+14.9** 个百分点。
- 同时**超越** 使用真实记忆的 oracle（PrediMem + GT memory，46.1/64.8），说明"回溯记忆"并不充分，过渡管理才是关键。
- 按类别看，BATON 在 **Occlusion**（50.0 vs. 39.1）和 **Counting**（68.8 vs. 31.4）上取得了最大优势；Sequence 也以 83.4 TSR 领先。
- 与"同一探索预算的另一种花法"比较：整任务探索的 Harness VLA 在 Sequence 上表现不错（82.0），但在 Occlusion 上**从未在探索阶段解决任何任务**（0.0 TSR），平均仅 26.9 TSR；BATON 用相同预算将平均成功率提升至 57.7%。
- BATON 将**已完成阶段的 73% 转化为完成任务**，为表中最高比率，说明剩余失败较少集中在边界处。

### 5.2 消融与分析实验

论文对核心机制进行了多维度分解验证：

1. **过渡记忆各组件消融**：
   - 仅保留调用过渡（invocation translation）：移除交接过渡与前瞻过渡后，长链任务中后继子任务在继承前序状态时频繁失稳，TSR 显著下降；
   - 加入交接过渡：能够修复前序残留状态，但无法解决"策略形态不匹配后继需求"的问题，在个别任务（如必须侧握放入微波炉的场景）中仍失败；
   - 加入前瞻过渡（即完整 BATON）：剩余失败主要出现在需要更复杂预留约束的任务中，整体成功率最高。
   - 三者叠加的收益表明三类过渡信息在功能上互补、互不替代。

2. **记忆迁移实验**：
   - 论文验证了过渡条目以"过渡类型"为键进行跨任务迁移的能力：在"释放到窄唇容器"边界上学习的过渡约束（如入口张开程度、放行高度）可迁移至另一个视觉结构相似但语义名称不同的任务（如从篮子到垃圾箱），在该任务中省去针对该边界的重新探索。
   - 实验显示，记忆迁移带来的提升集中在**边界修复**而非子任务内部技能调用，进一步说明边作为一等公民设计（edge-as-first-class）的价值。

3. **失败归因分析**：
   - 对未完成任务的剩余失败进行归因，发现完整 BATON 下失败中约 73% 发生在**已成功阶段的后续阶段**或**边界处**，说明"阶段本地成功但链条断裂"的问题已大幅缓解；
   - 与 Harness VLA 的对比中，Harness VLA 的长链任务失败几乎全部源于"整任务探索无法归因具体失败阶段"，而 BATON 的失败记忆使每次失败都能被显式写入对应子任务或边界，从而在下一轮探索中定向修复。

4. **探索预算效率分析**：
   - 论文以探索 episode 数为横轴、子任务解决率为纵轴绘制曲线，显示 BATON 在相同 episode 预算下解决的子任务数量远多于整任务探索；
   - 逐子任务探索的"加法成本"特性使预算消耗与 K 呈线性关系，而整任务探索在预算耗尽时往往仍未完成首个完整轨迹。

## 六、局限性与未来工作

### 6.1 主要局限性

1. **对 VLA 后端能力的依赖**：
   - BATON 冻结 VLA 并完全不更新参数，这意味着若某子任务所需的物理技能本身超出该 VLA 的能力边界（例如需要极高精度力控但 VLA 完全没有相应行为），即使探索与过渡管理再完善，该子任务也无法被解决。
   - 因此 BATON 的"上限"受限于后端 VLA 的行为覆盖范围，而非由自身算法决定。

2. **Verifier 仅基于腕部相机图像**：
   - 入口条件与就绪条件的验证完全依赖于腕部相机的局部视野。对某些需要全局状态判断的边界（如"目标容器是否位于桌面正确位置"），局部视觉可能无法覆盖，Verifier 可能给出错误判定。
   - 虽然论文通过解析原语修复了大部分状态，但修复能力也局限于可被重新定向、重新张开的自由度；若前序子任务将物体带到不可恢复的物理状态（如掉落、卡死），则系统无法自愈。

3. **需要机器人可执行解析原语**：
   - 调用过渡与前向交接的修复模块依赖一套解析原语（重新定向抓手、张开、重新布置等）来恢复边界状态。若场景中不存在这样的解析原语（例如物体被悬挂于空中且无任何可规划的恢复动作），则该边界无法被修复。

4. **LLM 智能体的 token 成本与延迟未量化**：
   - 论文未报告完整链式执行中 LLM 调用的 token 数、推理延迟或总体时间开销。由于每个子任务、边界与 VLA 调用之前均有 LLM 判断步骤，实际执行 wall-clock 时间可能不菲，这在真实机器人部署中是一个重要的工程约束。

5. **评估配置数量偏少**：
   - 每个任务仅探索 1 个参考配置、评估 2 个保留配置，样本量较小，无法给出严格的置信区间；对任务内方差（如不同初始物体位姿）的鲁棒性分析不足。

### 6.2 未来工作

- 探索将过渡记忆与 VLA 微调结合：在过渡条目足够丰富后，将边界条件蒸馏回 VLA 的策略表示中，减少对在线 LLM 判断的依赖。
- 扩展 Verifier 为多模态融合（腕部相机 + 全局相机 + 本体感觉），以覆盖更复杂的全局边界条件。
- 在更多样的机器人平台与任务族（如移动操作、灵巧手操作）上验证过渡记忆的迁移性与通用性。
- 研究失败记忆的自动摘要与遗忘机制，防止记忆库无限膨胀带来的检索效率下降。

## 七、总体评价

BATON 的核心贡献可以概括为三点：

1. **问题定位精准**：明确指出长时程操作失败的根因并非单个技能不熟练，而是技能之间的"过渡"缺乏显式表示与管理，这一视角在 VLA 类方法主导的当下具有重要的纠偏意义。

2. **方法论上优雅且务实**：不更新任何网络参数，通过冻结 VLA + LLM 智能体的分层探索与过渡记忆，将整任务探索的指数成本降为逐子任务探索的加法成本；三个过渡类型分别对应"VLA 调用时机"、"前序状态污染"与"后继形态约束"三个不同的失败模式，设计上逻辑清晰、可解释性强。

3. **实验结果有说服力**：在 26 个真实机器人任务、平均 1000+ 步的基准上取得显著领先，甚至超越使用真实记忆的 oracle 基线，表明过渡管理比简单的"记忆回放"更接近长程操作成功的本质。

同时，论文也留下了值得后续研究的重要问题：当后端 VLA 能力不足时如何扩展技能边界、Verifier 的局部视觉限制如何突破、以及 LLM 智能体的实际部署成本如何控制。总体而言，这是一篇问题意识强、方法设计完整、实验证据充分的高质量机器人学习论文。
