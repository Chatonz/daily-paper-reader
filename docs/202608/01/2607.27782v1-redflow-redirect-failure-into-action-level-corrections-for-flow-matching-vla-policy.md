## 摘要
流匹配视觉-语言-动作（VLA）策略在机器人操作方面展现出强大潜力，但常常因部署过程中的分布偏移而遭受累积错误。虽然离线强化学习（RL）提供了一种利用交互数据改进已部署策略的实用方法，但现有方法要么忽略失败数据，要么仅在轨迹层面利用它们，导致学习效率低下和错误持续存在。我们提出RedFlow，一个细粒度的离线RL框架，将失败经验重定向为流匹配VLA策略的动作级修正监督。RedFlow包含两个关键组件：（1）上下文感知的修正匹配机制，识别导致失败的动作，并从相似上下文检索成功替代动作作为修正目标；（2）自适应重定向目标，联合强化成功动作、抑制不良动作，并将可恢复的失败重定向至修正目标。通过将成功和失败经验转化为密集监督，RedFlow能够从混合质量数据中进行稳健的恢复学习。在LIBERO基准和三个真实世界操作任务上的实验表明，RedFlow始终优于最先进的离线RL基线，将真实世界成功率从56.7%提升至74.7%。同时，它在需要约一个数量级更少训练样本的情况下，与强在线策略方法（PPO、GRPO和DDPO）表现相当。

## Abstract
Flow-matching Vision-Language-Action (VLA) policies have shown strong potential for robotic manipulation but often suffer from compounding errors caused by distribution shifts during deployment. While offline reinforcement learning (RL) provides a practical way to improve deployed policies using rollout data, existing methods either ignore failure data or exploit it only at the trajectory level, resulting in low learning efficiency and persistent errors. We propose **RedFlow**, a fine-grained offline RL framework that redirects failure experiences into action-level corrective supervision for flow-matching VLA policies. RedFlow consists of two key components: (1) a **Context-Aware Corrective Matching** mechanism that identifies failure-inducing actions and retrieves successful alternatives from similar contexts as corrective targets, and (2) an **Adaptive Redirection Objective** that jointly reinforces successful actions, suppresses undesirable ones, and redirects recoverable failures toward corrective targets. By converting both successful and failed experiences into dense supervision, RedFlow enables robust recovery learning from mixed-quality data. Experiments on the LIBERO benchmark and three real-world manipulation tasks show that RedFlow consistently outperforms state-of-the-art offline RL baselines, improving the real-world success rate from 56.7% to 74.7%. It also matches strong on-policy methods (PPO, GRPO, and DDPO) while requiring roughly an order of magnitude fewer training samples.

## 1. 核心问题与整体含义

**研究动机：**
- 流匹配（Flow-matching）VLA（视觉-语言-动作）策略已成为通用机器人操作的主流范式，其基于流匹配模型学习从噪声到动作的速度场，可建模多模态动作分布。
- 然而，VLA策略通常通过**模仿学习**（行为克隆）在人类示范数据上训练，天然继承了行为克隆的根本缺陷：**部署时因分布偏移产生累积误差（compounding errors）**。当机器人遇到偏离训练分布的狀態时，微小预测误差逐步累积，最终导致不可恢复的失败。
- 强化学习（RL）可弥补这一差距，但在线RL方法需要大量真实环境交互，成本高昂；**离线RL**虽可利用预采集的部署rollout数据，但现有方法存在两大不足：
  1. **忽视失败数据**：经典离线RL方法（如AWR）主要对成功行为加权或模仿，丢弃了失败轨迹中丰富的诊断信息。
  2. **仅在轨迹层面利用失败**：基于偏好的方法（如DPO）虽学习失败，但只提供轨迹级比较，信号粗糙，缺乏**动作级修正指引**——它们告诉策略"不要做什么"，却不指明"应该怎么做"。
- 人类介入干预虽能提供动作级监督，但需要专家精力，不可扩展。

**核心研究问题：**
> 如何在不依赖人工干预的前提下，从预采集的失败经验中提取高保真的动作级修正信号，实现对策略的精确改进？

**两大挑战：**
1. **粒度失配**：轨迹级失败标签过于粗糙，无法定位导致失败的具体动作块（其中许多中间动作实际上是合理的），且难以在无密集人工监督下提取精确修正目标。
2. **信号整合**：流匹配策略传统上将所有动作视为等效样本来模仿，这种"统一模仿"在处理混合质量数据时会导致学习次优行为或过度纠正。

## 2. 方法论：RedFlow框架

### 2.1 整体架构

RedFlow是一个**细粒度离线强化学习框架**，包含三个阶段（见图2）：
- **阶段I：数据收集**——使用基础策略在环境中执行rollout，收集成功与失败轨迹存入离线缓冲区。
- **阶段II：上下文感知纠正匹配（Context-Aware Corrective Matching）**——估计每个动作块的质量标签，并从相似上下文的成功经验中检索纠正目标。
- **阶段III：自适应重定向目标（Adaptive Redirection Objective）**——基于三种互补的损失项更新策略。

### 2.2 动作级优势估计

- 使用预训练的**通用奖励模型（GRM）** R(o_t, l) 估计任务进度，经**箱式滤波器**平滑（窗口W）得 p̄_t：
  ```
  p̄_t = (1/(2W+1)) Σ_{j=t-W}^{t+W} R(o_j, l)
  ```
- 将平滑进度序列转化为**带符号的动作级得分**：
  ```
  Â_t = (p̄_{t+W} − p̄_{t−W}) + b·(2·1[y_τ=1] − 1)
  ```
  其中第一项为局部进度变化，第二项为轨迹结果偏差项（b>0）。
- 根据 Â_t 符号将动作块标记为"正"或"负"。

### 2.3 上下文聚类与纠正目标构造

- 定义**执行上下文**：利用本体感受状态 q_t 和平滑进度估计 p̄_t 构成进度-状态特征空间：
  ```
  f_t = [q̃_t; β·p̄_t]
  ```
  （本体感受状态捕捉机器人配置，进度隐式包含视觉信息，避免直接聚类高维视觉空间。）
- 使用**HDBSCAN**密度聚类算法对所有动作块聚类，形成执行上下文簇 {C_c}。
- 对于每个负动作块 a_t（Â_t<0），若所在簇 C_c 的正子集 C_c^+ 非空，则构造**质量加权纠正目标**：
  ```
  α_i = exp(Â_i/κ) / Σ_{j∈C_c^+} exp(Â_j/κ)
  a_t* = Σ_{i∈C_c^+} α_i · a_i
  ```
  （a_t* 是优势倾斜的正动作经验质心，定义局部传输方向，而非一对一的替换动作。）
- 若负动作块被HDBSCAN标记为异常点或所在簇无正样本，则标记为**不可纠正**，仅做抑制处理。

### 2.4 自适应重定向目标

整个目标函数包含三个互补项（总损失 L = L_att + L_sup + L_cor）：

1. **质量加权吸引（Quality-weighted Attraction）**：
   ```
   w_t = σ(Â_t/T_w) ∈ (0,1)
   L_att = w_t · ||v_θ(x_n, n, o_t, l) − u_n||²
   ```
   高质量动作块获得近似1的权重，强化正向行为；低质量动作块权重趋近0。

2. **失败抑制（Failure Suppression）**（铰链损失）：
   ```
   e_t = ||x̂_0 − a_t||²,  x̂_0 = x_n − n·v_θ(x_n, n, o_t, l)
   L_sup = λ_sup(1−w_t)·max(0, m − e_t)
   ```
   仅当预测动作距负样本小于边距m时施加排斥力，一旦远离则抑制失效（有限范围排斥）。

3. **目标引导纠正（Target-guided Correction）**：
   ```
   L_cor = c_t·λ_cor(1−w_t)||x̂_0 − a_t*||²
   ```
   c_t∈{0,1}指示是否为有纠正目标的失败块。吸引策略预测向纠正目标方向移动。

**理论支撑**（附录A）：三个损失项可视为**条件动作分布上的Wasserstein梯度流**的粒子级实现——正动作定义建设性传输目的地，负动作作为有限范围障碍物，行为锚定保持传输分布贴近缓冲区支持，整体构成"推力-拉力"传输场，具有能量耗散性质和局部平稳收敛保证。

### 2.5 训练流程

单次迭代离线后训练流程：
- 用预训练策略收集固定rollout缓冲区 → 用GRM估计进度并标注动作质量 → HDBSCAN聚类并分配纠正目标 → 用自适应重定向目标优化策略（30个epoch）。

## 7. 优点

1. **细粒度动作级监督**：不同于现有方法的轨迹级利用，RedFlow首次将失败转化为密集的**动作级修正信号**，识别具体导致失败的动作块并指明纠正方向。
2. **上下文感知的纠正匹配**：巧妙利用"本体感受状态+任务进度"定义执行上下文，避免直接处理高维视觉空间；HDBSCAN聚类使相似上下文的成功经验可为失败动作提供高质量纠正目标。
3. **自适应重定向目标设计**：三项互补损失（吸引/抑制/纠正）分别处理不同质量的动作块，避免了"统一模仿"的陷阱；铰链抑制损耗实现**有限范围排斥**，防止过度纠正。
4. **严格离线、无需额外交互**：完全从固定缓冲区学习，无需人类示范或额外在线交互，适合真实机器人应用场景。
5. **理论支撑扎实**：附录提供了从Wasserstein梯度流视角的形式化理论，将三个损失项统一为局部传输原理的粒子实现，并给出能量耗散和局部收敛保证。
6. **优异的样本效率**：与在线方法相比可减少约10倍rollout数据，显著降低真实机器人RL的成本。

## 8. 不足与局限

1. **依赖GRM质量**（论文明确承认）：纠正目标分配依赖预训练GRM的任务进度估计质量与HDBSCAN聚类的精度；不准确的进度信号或噪声聚类可能导致不完美的失败-成功匹配。
2. **仅能纠正有正支持可用的失败**（论文明确承认）：对于全新的、分布外的、或缺乏成功对照的失败模式，RedFlow只能施加抑制而无明确纠正，作用有限。
3. **大规模评估不够完整**：消融实验未覆盖LIBERO-Long；真实机器人仅验证3个任务、固定基座策略和固定夹具；未在多形态机器人、多样视觉条件和更长时域任务中广谱验证。
4. **统计严谨性欠缺**：未报告方差/置信区间和多次独立重复的结果，改进幅度（尤其在真实任务中）的统计可靠性不明确。
5. **对比方法范围有限**：离线基线仅比较了AWR和DPO，未覆盖更近期的离线RL方法（如Co-RFT、Diffusion Guidance等，虽在相关工作提及但未实验对比）；未与任何人类介入方法比较。
6. **超参数敏感度未探索**：λ_sup、λ_cor、κ、T_w、W、b等多个超参数需要调节，论文未报告灵敏度分析；Long套件的超参数调整虽给出解释，但未验证取值合理性。
7. **单次迭代离线设置**：仅执行一轮离线后训练，未验证在多次迭代（收集新数据再训练）下的表现，也未考虑离线-在线迭代提升的潜力（虽列为未来工作）。
