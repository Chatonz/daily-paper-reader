## 摘要
自我中心视频为具身AI提供了丰富的操作经验，然而在不同场景、物体、动作和实体之间收集多样化的自我中心数据仍然成本高昂。我们提出了\method，一个自我中心世界-动作模拟器，能够合成可控、高质量的操作视频，以扩充稀缺的真实世界训练数据。\method建立在预训练的视频生成先验之上，并引入了两种几何感知的条件机制。在线锚定投影记忆（OAPM）在自回归生成过程中保留第一帧的3D场景锚点，同时周期性地刷新最近状态。Action-3D旋转位置嵌入（A3D-RoPE）通过相机感知的3D旋转坐标编码末端执行器运动，将动作几何注入骨架到视频的交叉注意力中，以实现精确控制。这些组件共同提高了长程自我中心 rollout 的视觉保真度、几何稳定性和动作对齐。此外，用400条\method生成的轨迹增强400条真实轨迹，将单臂任务上的分布外真实机器人成功率从77\%提高到84\%，双臂任务从53\%提高到70\%，表明合成数据显著提升了下游WAM泛化能力。

## Abstract
Egocentric video offers rich manipulation experience for embodied AI, yet collecting diverse egocentric data across scenes, objects, motions, and embodiments remains costly. We present \method, an egocentric world-action simulator that synthesizes controllable, high-quality manipulation videos to expand scarce real-world training data. \method{} builds on a pretrained video generation prior and introduces two geometry-aware conditioning mechanisms. Online Anchored Projective Memory (OAPM) preserves a first-frame 3D scene anchor while periodically refreshing a recent state during autoregressive generation. Action-3D Rotary Position Embedding (A3D-RoPE) encodes end-effector motion with camera-aware 3D rotary coordinates, injecting action geometry into skeleton-to-video cross-attention for precise control. Together, these components improve visual fidelity, geometric stability, and action alignment in long egocentric rollouts. Moreover, augmenting 400 real trajectories with 400 \method-generated trajectories improves out-of-distribution real-robot success from 77\% to 84\% on single-arm tasks and from 53\% to 70\% on dual-arm tasks, demonstrating that the synthesized data substantially improve downstream WAM generalization.

## 2. 方法论

### 2.1 总体思路

EgoGenesis 建立在 **预训练视频生成先验** 之上，采用 **自回归 rollout** 的方式逐段生成第一人称操作视频。在生成过程中，通过两个关键模块将“3D 几何”和“动作几何”注入条件生成流程：

- **OAPM（在线锚定投影记忆）**：负责维持视频的 **几何稳定性与长期一致性**；
- **A3D-RoPE（Action-3D 旋转位置编码）**：负责实现末端执行器运动的 **精确动作控制**。

### 2.2 在线锚定投影记忆（OAPM）

- **核心问题**：长期自回归视频生成中，模型会逐渐遗忘初始场景的几何布局，导致物体漂移、场景畸变、3D 结构崩坏。
- **思想**：在自回归生成的整个过程中，**保留第一帧的 3D 场景锚点（anchor）作为全局几何参照**，同时**周期性刷新“近期状态”**，以兼顾动态变化与瞬时一致性。
- **工作方式**（文字描述流程）：
  1. 初始化时，从第一帧恢复/估计场景的 3D 结构，作为全局锚点；
  2. 每生成若干帧后，将最近的状态作为短期上下文刷新；
  3. 在生成下一个片段时，同时参考“3D 场景锚点”（保证不偏离初始几何）与“近期帧状态”（保证动作连续、物体运动连贯）；
  4. 锚点信息与近期信息被共同投影到生成器的注意力机制中，从而稳定长程 rollout 的几何结构。
- **意义**：该机制可视为一种“内外存结合”的记忆策略——锚点是持久化的几何记忆，近期帧是可替换的动态记忆。

### 2.3 Action-3D 旋转位置编码（A3D-RoPE）

- **核心问题**：如何将机器人末端执行器的连续运动轨迹精确注入到视频生成过程中，使生成画面的动作与真实动作序列对齐？
- **思想**：将末端执行器的运动信息编码为**相机感知的 3D 旋转坐标**，并利用与旋转位置编码类似的数学结构，将动作信息嵌入骨架到视频（skeleton-to-video）的交叉注意力层。
- **工作方式**：
  1. 将动作轨迹（末端执行器关键点的 3D 位置序列）转换为相对相机坐标系的 3D 旋转表示；
  2. 通过旋转位置编码（RoPE）的形式，将动作坐标映射为注意力计算中的位置偏差；
  3. 将编码后的动作信息注入到骨架条件与视频生成之间的交叉注意力模块中，令生成器在每一帧上都“感知”到当前应有的动作姿态；
  4. 这样，生成视频中手部/末端执行器的运动轨迹被几何约束在指定动作张成的流形上，实现动作级控制。
- **与 OAPM 的关系**：OAPM 负责“场景几何”稳定，A3D-RoPE 负责“动作几何”对齐，两者互补，共同提升长程 rollout 的视觉质量与动作一致性。

### 2.4 训练的总体数据流（文字描述）

1. 输入：初始帧 + 场景 3D 锚点 + 末端执行器运动轨迹（动作序列）；
2. 以自回归方式逐段生成后续帧；
3. 在每一步生成中，OAPM 提供场景锚点与近期状态，A3D-RoPE 提供动作条件的几何编码；
4. 输出：长序列、动作对齐、几何稳定的合成自我中心操作视频。

  - 未见消融实验（OAPM 有无、A3D-RoPE 有无、不同锚定刷新频率等）的量化结论；
  - 未见对长程 rollout 视觉质量的定量评估（如 FVD、LPIPS、成功率上限分析），目前仅有定性描述。
- **合成数据的天花板风险**：合成视频始终受预训练先验和动作估计质量的限制，复杂物理交互（如液体、可形变物体）可能难以被准确模拟，分布外优势可能只在有限范围内成立。
- **潜在偏差**：以 77%→84% 的增长率评估合成数据效用时，需注意真实数据的采样场景、任务难度分配、机器人形态是否与合成数据分布一致；这些在摘要中未说明。
- **算力信息缺失**：未提供 GPU 时数、模型参数量等，无法评估方法的训练成本与可复现难度。
- **下游模型范围窄**：仅针对“下游 WAM 泛化能力”进行验证，未覆盖传统模仿学习（如 Diffusion Policy、ACT）等常见操作策略框架，也未验证生成视频用于预训练世界模型后的规划性能。
