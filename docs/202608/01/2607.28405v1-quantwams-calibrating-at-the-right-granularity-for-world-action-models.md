## 摘要
世界行动模型（WAMs）联合预测未来的观测和动作，但其迭代去噪和闭环执行使得高效部署成本高昂。现有的训练后量化（PTQ）方法并不适用于WAMs，因为它们依赖于开环目标、同质模型假设以及不能反映部署情况的校准分布。我们提出QuantWAMs，一种PTQ框架，将量化决策与由模型结构、 rollout 分布和任务目标定义的校准上下文对齐。QuantWAMs引入了三种策略：共享基异常值校准，仅跨坐标兼容模块汇集激活证据；联合训练目标显著性，从联合视频-动作梯度计算经验Fisher分数，并在校准稳定的层粒度上分配权重精度；以及固定干预 rollout 审计，在不改变精度预算的情况下，使用可达闭环状态修订去噪步骤保护计划。我们在Fast-WAM和LingBot-VA上，在RoboTwin 2.0、LIBERO以及使用AgiBot G2的真实机器人操作中评估了QuantWAMs。在W4A4主导设置下，报告的模拟均值与FP16相差0.2-0.7个百分点。真实机器人试验进一步确立了在三个操作任务上的部署可行性。对于目标视频和动作块，QuantWAMs将峰值权重和激活内存减少到FP16的约29%，并提供1.4-1.6倍的块级加速。

## Abstract
World Action Models (WAMs) jointly predict future observations and actions, but their iterative denoising and closed-loop execution make efficient deployment costly. Existing post-training quantization (PTQ) methods are poorly suited to WAMs because they rely on open-loop objectives, homogeneous model assumptions, and calibration distributions that do not reflect deployment. We present QuantWAMs, a PTQ framework that aligns quantization decisions with the calibration context defined by model structure, rollout distribution, and task objective. QuantWAMs introduces three strategies: shared-basis outlier calibration, which pools activation evidence only across coordinate-compatible modules; co-training-objective saliency, which computes empirical-Fisher scores from the joint video--action gradient and assigns weight precision at a calibration-stable layer granularity; and fixed-intervention rollout auditing, which revises denoising-step protection schedules using reachable closed-loop states without changing the precision budget. We evaluate QuantWAMs on Fast-WAM and LingBot-VA across RoboTwin 2.0, LIBERO, and real-robot manipulation with an AgiBot G2. Under a W4A4-dominant setting, the reported simulation means differ from FP16 by 0.2--0.7 percentage points. Real-robot trials further establish deployment feasibility on three manipulation tasks. For the targeted video and action blocks, QuantWAMs reduces peak weight-and-activation memory to about 29\% of FP16 and provides 1.4--1.6$\times$ block-level speedups.

## 1. 论文核心问题与整体含义

- **背景**：世界行动模型（WAMs）将视频扩散世界模型与扩散动作专家相结合，联合预测未来观测及实现这些观测所对应的动作，是通用机器人操作领域一个有前景的范式。代表性实现包括 Fast-WAM 和 LingBot-VA。
- **痛点**：WAMs 的每个控制周期都需要迭代去噪，且以闭环方式运行（每一步生成的动作都会改变后续预测所依赖的观测），导致部署成本极高。后训练量化（PTQ）是降低部署成本的天然途径。
- **现有方法失败的原因**：
  - **开环目标不匹配**：多数 PTQ 方法（如 GPTQ、SmoothQuant、AWQ）以困惑度或单帧重建为优化目标，模型对量化误差缺乏沿时间维度的传播建模；
  - **同质结构假设**：经典 PTQ 假设模型是同构单流 Transformer，而 WAMs 拥有双流混合 Transformer 或共享扩散主干等多路径耦合结构；
  - **校准分布失真**：静态单流代理即使校准损失很低，也可能在真实部署（闭环 rollouts）状态下错配精度。
- **核心含义**：量化决策本质上是在部署前、在特定"校准上下文"（结构范围 G、状态分布 D、目标函数 L）下做出的有限样本估计。只有当这三个要素在部署时仍然成立，量化决策才有用。QuantWAMs 正是按这一原则逐轴对齐校准上下文。

## 2. 方法论

QuantWAMs 是一个面向 WAMs 的 PTQ 框架，包含三大核心策略。

### 2.1 共享基异常值校准（Shared-Basis Outlier Calibration）

- **目标**：决定激活异常值掩码（Top-K 通道保留在高精度）在哪些模块/上下文之间可以共享池化（pooling），减少有限样本估计的方差。
- **关键技术细节**：
  - 保留 Atom 的平方和通道统计量和混合精度执行原语；贡献在于确定该统计量可以在哪些校准上下文内池化。
  - 每个上下文 i 指定模块、执行模式和深度；对每个轨迹 n 的激活 $A^{(n)}_i$，先施加以 Hadamard 旋转 R 和逐上下文对角平滑矩阵 $S_i$，再收集统计量。
  - 定义逐上下文均值 $e_i(c)$、池化估计 $\hat{e}_g(c)$ 等；共享约束下的最优掩码为 $TopK_K(\bar{e}_g)$。
- **坐标可容许性（Coordinate Admissibility）**：
  - 只有当日志索引表示相同量化输入坐标时才能共享。公共旋转 R 在整个群组中固定一个有序基；上下文特定的对角缩放不会改变坐标身份，但上下文特定的稠密旋转会使字面索引共享失效。
  - Fast-WAM 中共享值路径对齐配对输出投影可共享；专家私有残差流不允许跨专家 Q/K/V 共享。LingBot-VA 中跨模式复用同一物理 Linear 的输入列时，若融合后的列变换共享或保坐标，则允许跨模式共享。
- **池化交叉点理论**：建模每个通道统计量 $\hat{z}^{(n)}_i(c) = \mu_g(c) + \tau_c \eta_i(c) + \sigma_c \xi^{(n)}_i(c)$；
  - 命题 1：当跨成员异构性 $\tau^2_c > 0$ 时，池化降低风险恰在 $N < N^\star_c = \sigma^2_c / \tau^2_c$ 时成立。若 $\tau^2_c = 0$，池化始终更优。
  - 进一步给出Top-K掩码恢复的指数概率界（公式8），以及基于32条校准轨迹的 Bootstrap 稳定性分析与 $N^\star$ 估计（公式9）。
- **关键原则**：只池化满足坐标可容许且 $N_{cal} < \hat{N}^\star_g$ 的组，并以 Bootstrap 掩码稳定性作为额外筛选条件。

### 2.2 联合训练目标显著性（Co-Training-Objective Saliency）

- **目标**：决定逐层权重精度分配（哪些层升级到 W8），使用联合视频-动作共训练目标的经验 Fisher 信息，而非单流目标或事后融合目标。
- **核心公式**：
  - 联合目标 $\ell_{co} = \lambda_v \ell_v + \lambda_a \ell_a$；
  - 定义 $G^{joint}_L = \lambda^2_v G^v_L + \lambda^2_a G^a_L + \lambda_v\lambda_a(\Xi_L + \Xi^\top_L)$，其中 $\Xi_L = E[g_{v,L} g^\top_{a,L}]$ 为跨流梯度的坐标级对齐项；
  - 事后融合（post-hoc Fusion）缺失 $2\lambda_v\lambda_a E[g_{v,L} \odot g_{a,L}]$ 这项——即先平方再融合丢弃了坐标级交互信息。
- **精度分配机制**：
  - 使用 Kronecker 分解经验 Fisher 近似，计算比特级失真 $D_L(b) = \frac{1}{2} tr[G_L \epsilon^{(b)}_L \Sigma_L (\epsilon^{(b)}_L)^\top]$；
  - 用0-1背包选择升级哪些层：$\max \sum_L z_L B_L$ 使 $\sum_L z_L c_L \le B$，其中 $c_L=1$、$B=\lfloor 0.2|\mathcal{L}|\rfloor$，即升级 top 20% 候选 Linear。
- **粒度选择**：元素级排名不稳定，列级分数仅用于 GPTQ 内部排序启发式，实际精度分配使用层总量（layer totals）——校准稳定的层粒度。
- **不更新预训练权重**，仅需原共训练目标和一次反向传播（梯度辅助 PTQ）；GPTQ 补偿仍由 $\Sigma_L$ 主导。

### 2.3 固定干预滚动审计（Fixed-Intervention Real-Rollout Auditing）

- **目标**：确定去噪步骤保护计划（哪些去噪步使用 A8），修复现有 K 步计划，而不改变精度预算。
- **关键洞见**：WAMs 中，先前控制调用产生的动作改变后续观测。合成/开环输入上构建的敏感度概况可能测到了"错误状态上的正确局部差异"。
- **三种概况对比**：
  - $S_{syn}(t)$：合成状态分布，遗漏可达 rollout 历史；
  - $S_{obs}(t; q)$：真实状态但被当前保护计划遮蔽（被保护的步骤因精度已经提高而显得不敏感）；
  - $S_{replay}^{ref}(t)$：固定干预——每个记录状态在相同的未保护干预 $q_0$ 下重放，消除自遮蔽。
- **实施方式**：对每个分支恢复完整不可变 FP16 快照、深度复制持久状态、匹配随机种子。提出的修复计划 $T^{replay} = TopK_{t\in[T]} S^{replay}_{ref}(t)$，与 $|T_q|=K$ 相同，因此只改变保护位置、不改变精度水平和数量。
- **重要限定**：概况值仅用于提出受控的计划修复，不作为边际任务增益的估计（闭环任务影响还取决于转移雅可比乘积 $A_j$、$B_j$）。
- **数据分离**：概况用 32 条与 PTQ 校准轨迹不相交的 FP16 闭环 rollouts 估计；修复计划在独立的验证集上确认后冻结，再进入最终测试。

## 5. 主要结论与发现

- **主结果**：在 W4A4 主导设置下，QuantWAMs 在 Fast-WAM 上 RoboTwin 2.0 平均成功率与 FP16 相差 0.2 个百分点（91.7 vs 91.9）、LIBERO 相差 0.2 个百分点（97.4 vs 97.6）；在 LingBot-VA 上分别相差 0.7（91.6 vs 92.3）和 0.5（98.0 vs 98.5）个百分点。

- **对比优势**：显著优于 SVDQuant*、Atom* 等同预算匹配基线（如 Fast-WAM LIBERO 平均：QuantWAMs 97.4 vs Atom* 82.1 vs SVDQuant* 75.3）。
- **消融层级**：共享基校准贡献最大（+8.3/+9.4）、联合显著性次之（+1.8/+2.2）、固定干预重放同样显著（+4.1/+6.2）（Fast-WAM/LingBot-VA，LIBERO-Long）。
- **真实机器人**：FP16 19/30 成功，QuantWAMs 17/30，Atom* 12/30——量化策略可执行全部三项任务，但不可视为与 FP16 等价。

## 7. 论文不足与开放问题

1. **效率报告不完整**：唯一的硬件收益指标是块级"峰值内存+块加速"（29% 峰值内存、1.4–1.6 倍块加速），缺少真实机器人控制周期、端到端视频-动作生成延迟、吞吐量、能耗、端到端功耗等部署关键指标。29% 是块级峰值而非全模型稳态，不能直接外推到机器人整周期收益。
2. **算力与复现信息缺口**：未说明 GPU 数量、训练/校准时长、总预算等。这对一个方法论论文是明显的可复现性短板。
3. **真实评估规模过小**：真实机器人每任务仅 10 次试验，30 vs 19（FP16）的差异不足以做出统计上稳固的等价性/非劣性结论，也未做任何显著性检验。论文自述真实实验结果仅能表明"可执行任务"。
4. **消融泛化性受限**：全部消融只在 LIBERO-Long 上进行，Fast-WAM 的 RoboTwin 2.0 等主要基准没有消融数据。论文也承认消融结果不能做严格因果归因（方法差异不唯一）。
5. **存在未展开的机制细节**：
   - 校准集（32 条轨迹）的具体构建方式（长度、任务分布、负样本比例）未详述；
   - 异常值通道比例（2%）与 Top-K 的 K 值是否做过敏感性分析未报告；
   - SVDQuant* / Atom* 在 Blackwell NVFP4 内核下的具体适配方式没有完全说明，存在潜在的内核差异混淆；
   - LingBot-VA 未做真实机器人评估，两个模型之间无法在真实场景上直接横向比较。

## 8. 结论

QuantWAMs 将 WAMs 的 PTQ 问题重新定义为"校准上下文的逐轴对齐"：通过共享基异常值校准对齐结构范围，通过联合训练目标显著性对齐目标函数，通过固定干预滚动审计对齐状态分布。在 Fast-WAM 和 LingBot-VA 上，它以 W4A4 主导（20% 层升级 W8、2% 异常旁路）实现了与 FP16 几乎持平的仿真成功率（差距 ≤ 0.7 个百分点），峰值内存降到约 29%，并显著优于同预算匹配的 SVDQuant*、Atom* 基线。真实机器人上，量化模型可以执行全部三项任务，但规模有限。整体而言，QuantWAMs 是首个系统性地为世界行动模型设计三对齐量化方案的工作，其贡献不限于某两个模型，而在于确立了"结构—目标—分布"三位一体的校准上下文理论，为后续通用机器人操作中的高效部署研究提供了一个清晰而可扩展的基准框架。未来工作应补充端到端效率指标、扩大真实试验规模、验证跨基准消融稳定性，并探索将方法扩展到更一般的视频-语言-动作统一模型。

## 9. 关键术语与缩写速查

| 缩写 | 含义 |
|---|---|
| WAMs | World Action Models，世界行动模型，联合预测未来观测与动作 |
| PTQ | Post-Training Quantization，后训练量化 |
| DiT | Diffusion Transformer |
| W4A4 / W8A8 | 权重/激活均为 4/8 bit 量化 |
| A8 | 激活 8 bit 保护 |
| FP16 / BF16 / FP8 / NVFP4 | 浮点精度格式；NVFP4 为 NVIDIA Blackwell 上的 4 bit 浮点格式 |
| Top-K | 按通道统计量取前 K 个通道保留高精度 |
| Rollout | 闭环 rollout，控制策略与环境交互的轨迹展开 |
| Fisher / 经验 Fisher | 基于梯度的二阶信息估计，用于显著性度量 |

| AgiBot G2 | 真实双臂机器人平台 |

**一句话总结**：QuantWAMs 通过"结构范围—目标函数—状态分布"三轴校准上下文对齐，在 W4A4 主导设置下让世界行动模型与 FP16 仿真成功率几乎无差距，显著优于同预算强化基线，但在端到端效率指标、算力透明度和真实试验统计效力上仍有明显改进空间。
