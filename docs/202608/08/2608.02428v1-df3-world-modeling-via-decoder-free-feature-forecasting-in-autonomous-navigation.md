## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前的基于像素级别的生成方法不可避免地过度强调与任务无关的细节，导致巨大的计算开销。虽然基于潜变量的方法试图通过直接预测特征来缓解这一问题，但状态到任务映射中对重型解码器的持续依赖仍然是计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF$^3$），一种全新的框架，完全在潜空间内建模世界演化并直接生成任务输出，从而完全消除了对解码器的需求。具体来说，DF$^3$ 将可学习的空间查询注入冻结的视觉基础模型的终端块，直接提取未来状态表示。通过采用轻量级、统一的运动感知上下文融合（MACF）机制，无缝集成粗粒度光流扭曲与细粒度潜变量互相关，这些查询与历史令牌表示交互，以显式对齐和预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准上的大量实验以及在机器人模拟器中的零样本部署表明，DF$^3$ 在实现与最先进方法相当的性能的同时，为集成感知与控制提供了更高的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 二、方法论

### 2.1 核心思想

DF³ 的核心思想是**在冻结的 DINO 系 ViT 编码器的末端块中注入可学习查询**，利用预训练编码器自身强大的语义表征能力完成未来特征预测和下游任务提取，全程无需任何解码器。

### 2.2 整体流程

1. **上下文特征提取**：将 T 帧历史图像分别输入冻结 ViT，取早期层 L1 的输出作为上下文特征 $F_{L1}(I_t)$（含前缀令牌与空间块令牌）。
2. **预测查询注入**：将一组可学习的**预测查询** $Q_{pred}$ 与历史上下文特征拼接，共同送入编码器末端块 L2 进行处理。
3. **运动感知上下文融合（MACF）**：L2 输出的查询特征经 MACF 模块与历史帧特征交互对齐，得到最终预测的下一帧特征 $\hat{F}_{L1}(I_{T+1})$。
4. **任务查询注入**：将预测特征作为下一帧表示，注入一组**任务查询** $Q_{task}$ 再次送入 L2 块，输出经轻量 MLP 头得到任务结果（如语义分割图）。

### 2.3 关键技术细节

- **结构化查询注意力**：在注入查询的注意力层中施加非对称掩码。上下文令牌之间可自由交互，但禁止关注预测查询；预测查询可关注所有令牌，防止信息泄漏。

- **运动感知上下文融合（MACF）**，包含两条并行分支：
  - **光流扭曲分支**：从查询预测稠密潜空间光流场 Δp，将最近帧特征扭曲到未来，计算与查询的差异作为粗粒度更新方向。
  - **潜变量互相关分支**：在前一帧与最近帧之间进行局部窗口软匹配，计算历史语义运动矢量，作为细粒度运动注入。
  - 两分支输出经**门控机制动态融合**，得到最终预测特征。全局前缀令牌则通过轻量时间外推器处理。

### 2.4 训练目标

- 使用余弦相似度 + Huber 损失的组合，对预测特征与真实冻结特征的补丁令牌和前缀令牌同时进行监督。

## 六、主要结论与发现

1. **无解码器范式可行**：DF³ 验证了完全在冻结 ViT 编码器内进行未来特征预测和任务输出的可行性。
2. **精度-效率平衡优秀**：相比 DINO-Foresight，FLOPs 降低 36%、延迟降低 70%（降至 292ms/帧）、峰值内存降低 67%、参数量降低 41%，而 mIoU 仅下降约 2 个点。
3. **运动建模为关键**：消融证明显式运动建模（光流扭曲 + 互相关）对潜空间预测至关重要，两者互补效果最佳。
4. **零样本跨本体泛化**：在 Cityscapes 上训练的模型可直接部署到四足机器人模拟器，生成与 Oracle 高度对齐的规划轨迹，验证了潜空间特征的强泛化性和可迁移性。

## 七、优点

1. **范式创新**：首次提出"无解码器"的潜空间世界建模框架，打破了对重型解码器的路径依赖。
2. **架构轻量优雅**：查询注入 + 冻结编码器 + 轻量 MLP 的设计简洁高效。
3. **MACF 机制设计精巧**：将光流扭曲（粗粒度全局位移）与潜变量互相关（细粒度局部匹配）有机结合，配以门控融合，在不大幅增加参数的前提下有效建模运动。
4. **灵活解耦**：预测查询与任务查询独立训练，便于根据不同下游任务灵活替换。
5. **实际部署验证**：在真实模拟器中完成零样本部署，展示了从算法到应用的良好转化能力。

## 八、不足与局限

1. **不支持动作条件预测**：当前框架仅支持观测驱动的被动预测，无法根据机器人动作/控制指令进行条件预测，限制了在闭环控制中的应用（论文已明确承认）。
