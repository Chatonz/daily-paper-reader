## 摘要
接触丰富的操作失败往往仅在机器人已经发生接触之后才被检测到。这在腕部相机设置中尤其受限：夹爪-物体的近距离视图有助于观察接触，但在传统检测器做出反应之前，糟糕的接近动作可能已经推动、错过、滑动或扰动物体。我们提出了 ContactGuard，一种用于分块视觉运动策略的接触前执行监控器。给定策略规划的动作块，ContactGuard 在潜在视觉空间中预测其短期后果，如果预测的未来潜在表示表明可能失败，则中止执行。其潜在世界模型从无标记的机器人轨迹中训练，在规划动作下预测紧凑的多视图视觉嵌入，避免了像素级视频预测。随后，利用一小批带标记的接触前片段训练一个轻量级失败检测器。部署时，ContactGuard 在即将发生的接触事件之前锚定预测，在策略自身动作下向前推进模型，并验证预测的接触后潜在表示。在真实世界的接触丰富操作任务中，ContactGuard 比直接预测和动作损坏的消融方法更准确地预测失败，并能作为接触前中止信号迁移到实际机器人，而无需修改底层策略。

## Abstract
Contact-rich manipulation failures are often detected only after the robot has committed to contact. This is especially limiting in wrist-camera setups: close gripper--object views help observe contact, but a poor approach may already push, miss, slip, or disturb the object before conventional detectors react. We introduce \emph{ContactGuard}, a pre-contact execution monitor for chunked visuomotor policies. Given the policy's planned action chunk, ContactGuard predicts its short-horizon consequence in latent visual space and aborts if the predicted future latent indicates likely failure. Its latent world model is trained from unlabelled robot trajectories to predict compact multi-view visual embeddings under planned actions, avoiding pixel-level video prediction. A lightweight failure probe is then trained from a small labelled set of pre-contact clips. At deployment, ContactGuard anchors prediction before an imminent contact event, rolls the model forward under the policy's own actions, and verifies the predicted post-contact latent. Across real-world contact-rich manipulation tasks, ContactGuard predicts failure more accurately than direct and corrupted-action ablations, and transfers to live robot as a pre-contact abort signal without modifying the underlying policy.

## 1. 论文的核心问题与整体含义

接触丰富的机器人操作（contact-rich manipulation）中，大量失败在机器人已经与物体发生物理接触后才暴露出来。传统的执行监控器（如 success/failure detector）通常在接触发生后才能做出反应，这存在一个关键的时间盲区：在腕部相机等近距离监控设置下，即使观测条件有利于观察接触，策略的一个糟糕接近动作本身可能已经导致推挤、错过、滑移或扰动物体，造成不可逆的场景扰动。

ContactGuard 针对这一"接触前"（pre-contact）时间窗口提出了一个核心研究问题：**能否在机器人真正接触物体之前，根据策略即将执行的动作块（action chunk），预判这次交互是否大概率失败，并在接触前中止执行？**

整体含义是：将"事后检测"转变为"事前验证"——监控器不是被动观察失败，而是主动模拟动作后果，像一个门卫一样在接触事件之前进行否决。这种范式允许机器人在不修改底层策略的前提下，对高风险动作进行拦截，提升接触丰富操作的整体鲁棒性。

## 2. 论文提出的方法论

### 核心思想

ContactGuard 基于 **联合嵌入预测架构（JEPA）** 原则构建，核心出发点是：执行监控不需要生成像素级的逼真未来帧，只需要一个保留"结果相关信息"（即该交互是否会成功）的紧凑表示。因此，它预测的是**观测的未来潜在嵌入**（latent embedding），而非像素，从而绕开了视频生成的高昂代价和歧义性。

### 关键技术细节

**（1）两阶段训练/使用架构**：

- **阶段一（无监督潜在动力学学习）**：从一个共享的多视图视觉编码器（ViT-Tiny）将多相机观测编码成紧凑的 D=192 维潜在表示（跨视图均值融合）；一个动作条件因果预测器（4 层 AdaLN-zero 调制的 Transformer + 预测 MLP）在给定历史潜在上下文和动作的条件下，预测下一时刻的潜在表示。该世界模型使用**无标记的机器人轨迹**训练，采用 teacher-forced 的 next-latent 回归和 SIGReg 反坍缩正则化器。
- **阶段二（小数据监督失败探针）**：世界模型冻结后，使用一小批带人工标注的接触前抓取片段（约 250 个尝试/任务），训练一个**轻量级 ℓ2 正则化逻辑回归探针**，将预测的接触后潜在表示映射为失败概率 P(fail)。

**（2）训练目标**：
对于每个有监督步骤，预测器接收长度为 C 的真实潜在上下文和对齐动作，最小化预测潜在与真实潜在之间的 MSE，并加 SIGReg 正则项：
\[
\mathcal{L} = \frac{1}{L}\sum^{L-1}_{i=0}\|\hat{z}_{i+C} - z_{i+C}\|_2^2 + \lambda \mathcal{L}_{\text{reg}}
\]
训练时用 teacher-forcing 滑动上下文；部署时用自回归滚动。

**（3）在线部署流程**（四阶段）：

- **触发（Trigger）**：扫描即将执行的动作块，检测夹爪从开到闭的切换指令（策略无关的启发式），作为即将发生接触的事件信号。
- **锚定（Anchor）**：在预计夹爪闭合前 kpre=15 帧（0.5 秒）激活监控。
- **滚动与打分（Rollout & Score）**：编码观测历史，将动作块通过冻结的世界模型自回归滚动 K=30 步（到达闭合后 0.5 秒），用冻结的探针对预测潜在 \(\hat{z}_{t+K}\) 打分。
- **中止决策（Abort Decision）**：若 P(fail) > τ（阈值在验证集上选取后固定），在接触前中止执行；否则策略不变继续运行。

**（4）特征设计**：
- 多视图融合：V 个相机的嵌入共享一个编码器，均值池化后经线性投影产生单一潜在向量，保持维度与相机数无关。
- 动作嵌入器：1×1 时间卷积 + 两层 MLP。
- 预测器：4 层 AdaLN-zero 因果 Transformer（8 头，头维度 64，FFN 隐藏层 1024），预测投影为 2 层 MLP（隐藏维度 768）。

## 3. 实验设计

### 场景与数据集

- **机器人平台**：14 自由度 AgileX Piper 双臂机器人，三个同步 RGB 相机（腕部相机 + 外部视角）。
- **任务设定**：四类接触丰富抓取任务——
  1. Pick-and-place（杯子）
  2. Pick-and-place（盒子）
  3. Pencil-and-notebook（铅笔抓取）
  4. Towel-fold（毛巾折叠抓取）

  这四类任务要求接近接触时末端执行器与物体的精确对齐，小的接近误差即导致抓空、滑移或物体扰动。

- **数据组成**：
  - 世界模型训练数据：无标签的真实机器人轨迹（ACT 策略滚动 + 人工遥操作）。
  - 探针训练数据：提取的抓取尝试，人工标注二元成功/失败标签；每任务约 250 个尝试。
  - 测试集：单独采集，排除在世界模型训练、探针拟合、阈值选择和消融调参之外。
  - 在线评估：每任务 N=50 个实时受监控的 ACT 滚动。

### 对比方法

| 方法 | 说明 |
|---|---|
| **Ours（ContactGuard）** | 多视图动作条件 JEPA 滚动 + 线性失败探针 |
| **LeWM** | 容量匹配的单相机世界模型（同一训练轨迹） |
| **Direct-linear** | 绕过滚动，直接用锚点潜在 \(z_t\) 和计划动作块经线性逻辑回归分类 |
| **Direct-MLP（small/large）** | 非线性直接分类器（2/3 层 MLP，扫超参数） |
| **Current latent** | 与 ContactGuard 使用相同编码器、标签、探针家族和数据池的唯一区别：用当前潜在 \(z_t\) 替代预测未来潜在 \(\hat{z}_{t+K}\) |
| **FAIL-Detect** | 仅成功数据的运行时分布偏移检测器 |

| **LeWM + state** | 单视图世界模型加入 28 维关节位置/力矩的本体感受融合 |

### 评价指标

精确率、召回率、假中止率（FAR=FP/(FP+TN)，越低越好）、ROC AUC、平衡准确率。所有指标在触发的接触前状态评估，而非评估触发器本身或中止后恢复。

## 6. 论文的主要结论与发现

1. **多视图潜在世界模型带来显著增益**：ContactGuard 在全部四项任务上，平衡准确率和 AUC 均超过单视图 LeWM 基线；增益最大在 Towel 任务（单一视角下夹爪-布料接触区域频繁遮挡），最小在 Box 任务（单视图基线已较强）。

2. **想象未来优于直接分类**：预测的未来潜在表示比"当前潜在表示 + 计划动作"的直接监督分类更能表达失败风险。在线上评估中，Direct-linear 在每项任务上 AUC 均落后，且频繁产生劣质分离导致过多假中止。

3. **动作对齐至关重要**：将动作块打乱跨轨迹洗牌后，AUC 跌至接近随机（0.48-0.54）；置零和均值化也显著低于正确对齐的滚动。动作交换测试中，保持观测不变、仅替换失败动作块，预测失败概率在各任务上提升 +0.25 到 +0.65，证明监控器响应的是"具体待执行动作"而非静态视觉风险。

4. **本体感受融合在小数据下反而有害**：将 28 维关节位置/力矩直接拼接进单视图模型，各任务测试 AUC 显著下降（如 Cup 从 0.920 降至 0.660）。论文将原因解读为小型数据体制下状态融合充当了与抓取无关的捷径，而非认为本体感受本身有害。

5. **现有外部失败检测器不适用于接触前设置**：仅成功数据驱动的方法（FAIL-Detect、RND）在该预接触场景中与失败风险不对齐（部分任务 AUC 低至 0.2）；SAFE 表现较强但仍低于 ContactGuard。

6. **实际可部署性**：全流程约 19 ms 的推理延迟远低于 0.5 秒的接触前时间预算，监控器不会成为控制瓶颈。

## 7. 优点

1. **问题定义清晰且实用**：明确提出"接触前执行监控"这一具体且重要的问题设置，与分块视觉运动策略（如 ACT、Diffusion Policy）的自然结构契合。将监控定义为对策略拟执行的具体动作块的后果验证，具有明确的应用接口。

2. **策略解耦设计**：将底层策略视为黑盒提议器，不访问其内部、不联合训练、不修改策略输出，只需当前观测与已发出的动作块。这种"即插即用"的监控器可附加到任何分块策略上。

3. **有效利用无标签数据**：潜在世界模型从无标记轨迹中学习视觉动力学，仅需少量标注样本（约 250 个/任务）训练线性探针，大幅降低了标注成本。

4. **避免像素级预测**：潜在空间中的动作条件预测绕开了视频生成的计算成本和模糊性，兼顾了信息保留度与效率。

5. **消融设计严密**：Current latent 对照将"当前状态 vs. 想象未来"的差异隔离到仅一变量；动作交换检验以纯逻辑方式证明了动作因果性，而非简单的相关性；这些都是方法论上的亮点。

6. **实机验证充分**：不只是离线评估，还在真实机器人上进行了受控中止决策的闭环验证，验证层级完整。

## 8. 不足与局限

1. **只防止失败，不处理恢复**：ContactGuard 通过跳过接触来预防失败，但中止后不提供恢复策略或任务完成路径。论文明确将恢复方案留作未来工作，这意味着在实际部署中需要一个额外模块来接管被中止的任务。

2. **短视界限制**：监控目标仅限于"结果在下一个动作块内确定"的即将接触事件。对更长期技能或需要多层次接触决策的任务，需要分层或重复的事件级监控扩展。

3. **触发器是任务特化的启发式**：当前触发器仅为夹爪开→闭转换，策略无关但需要人工指定；对更一般接触事件（如插入、推挤）的通用触发器设计论文坦言是正交的开放问题。

4. **小数据体制下的表示学习偏差风险**：本体感受融合在小样本下反而损害性能，表明在小型数据范围内，表征学习的稳定性有待提高；更大的数据集或更复杂的融合策略可能改变这一结论，但未探索。

5. **实验覆盖有限**：仅四类抓取任务（且多为单臂操作），未涉及双臂协调、动态操作、可变形物体之外的接触场景。Pencil 任务还暴露出窄训练分布下增益有限的问题（当前潜在消融 AUC 已接近完整模型）。

6. **不具备生成/修复能力**：该方法是纯粹的否定式监控器，不尝试纠正动作、重新规划或产生备选策略；其价值完全依赖于底层策略本身具备一定的成功率。

7. **资料透明度不足**：未披露训练用的 GPU 资源和总训练成本；每任务只有 250 个标注样本和 50 个实时评估样本，统计效力可能有限。且未与 SIRIUS / Sirius-Fleet 等最接近的运行时监控工作做直接实验对比。
