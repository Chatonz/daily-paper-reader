## 摘要
接触丰富的操作仍然具有挑战性，因为成功的控制依赖于通常仅从视觉中难以微弱观察到的物理交互线索。近期基于触觉的世界动作模型联合建模未来的视觉观察和触觉信号以指导动作生成，但对于这些未来状态应如何结构化以供动作专家有效使用，仍未被充分探索。直接通过学习的世界动作模型研究这个问题是困难的，因为端到端行为纠缠了物理上无效的视觉未来、不可靠的预测、不准确或跨模态不一致的触觉预测，以及不可读的未来到动作接口。为了使该接口可独立研究，我们引入了Oracle视觉-触觉预见（OVTF），这是一个受控框架，提供从仿真中验证的成功轨迹中提取的配对RGB和触觉未来。通过固定未来提供者，OVTF隔离了接口并提出了一个更清晰的问题：如果未来是成功且物理可执行的，哪种表示允许动作专家吸收其益处？在OVTF内，我们提出了非对称相位局部未来记忆（AFM），其中视觉记忆读取未来视觉，每个触觉记忆联合关注其自身的触觉流和相位对齐的未来视觉，并阻断跨触觉访问。我们将AFM与模态隔离未来记忆（IFM）进行比较，后者移除视觉到触觉的访问并独立处理每种未来模态。在UniVTAC仿真基准的七个任务中，AFM实现了32.0%的平均成功率，而IFM为23.7%，UniVTAC-ACT为14.9%。这一受控比较表明，选择性的相位对齐视觉-触觉路由比完全模态隔离提供了更可行的未来到动作桥梁。

## Abstract
Contact-rich manipulation remains challenging because successful control depends on physical interaction cues that are often weakly observable from vision alone. Recent tactile world action models jointly model future visual observations and tactile signals to guide action generation, but how such futures should be structured for effective use by the action expert remains underexplored. Directly studying this question with learned world action models is difficult because end-to-end behavior entangles physically invalid visual futures, unreliable predictions, inaccurate or cross-modally inconsistent tactile forecasts, and an unreadable future-to-action interface. To make this interface independently studyable, we introduce Oracle Visuo-Tactile Foresight (OVTF), a controlled framework that supplies paired RGB and tactile futures from successful trajectories verified in simulation. By fixing the future provider, OVTF isolates the interface and asks a cleaner question: if the future is successful and physically executable, what representation allows the action expert to absorb its benefit? Within OVTF, we propose Asymmetric Phase-Local Future Memory (AFM), in which visual memory reads future vision, each tactile memory jointly attends to its own tactile stream and phase-aligned future vision, and cross-tactile access is blocked. We compare AFM with Modality-Isolated Future Memory (IFM), which removes visual-to-tactile access and processes each future modality independently. Across seven tasks on the UniVTAC simulation benchmark, AFM achieves 32.0% average success, compared with 23.7% for IFM and 14.9% for UniVTAC-ACT. This controlled comparison shows that selective phase-aligned visual-tactile routing provides a more actionable future-to-action bridge than complete modality isolation.

## 方法论：核心思想、关键技术细节

### 核心思想

论文主张点对点地解耦影响变量：将"未来预测是否正确"与"接口设计是否有效"分开。OVTF 用一个来自成功演示轨迹的 oracle 未来替代学习式预测器，使得接口可以在受控条件下被独立研究。

### OVTF 框架：Oracle 未来来源与编码

- 在每个策略调用时，当前观测包含头部/腕部 RGB 视图、左右触觉 RGB 图以及 8 维关节位置向量 `qt`。
- Oracle 未来**不是**连续预测的 `t+1 : t+H` 片段，而是从与当前初始化配对的一条成功 HDF 演示轨迹中采样得到。
- 相位定义：对参考索引 `τref`，从 `τref`（含）到轨迹末帧 `T−1` 均匀采样至多 `N=100` 帧，归一化剩余水平相位为：
  \[
  \phi_i = \frac{\tau_i - \tau_{ref}}{\max(1, T-1-\tau_{ref})}, \quad \phi_i \in [0,1]
  \]
- 训练时随机采样参考索引；rollout 时根据策略调用序号 p 按 `τref = min(⌊p/2⌋, T−1)` 确定。
- Oracle 仅提供 RGB 未来帧和左右触觉 RGB 帧，**不提供**未来动作、未来 qpos、物体位姿、仿真器状态、成功标签等特权元数据——因此它是一个"特权诊断源"而非学习式预测器。
- 未来视觉帧和触觉帧由可训练的 ResNet-18 编码（初始化为 UniVTAC-ACT* 编码器权重的深拷贝），生成三个序列：`H, L, R ∈ R^{N×512}`。
- 每个序列经过门控局部时间残差（gated local temporal residual）：
  \[
  X'_m = X_m + \tanh(g_m) \cdot \text{ConvDW}(\text{LN}(X_m))
  \]
  其中深度可分离卷积核大小为 5，门 `g_m` 初始化为零，保证初始时抑制新引入的残差。

### AFM：非对称相位局部未来记忆（Asymmetric Phase-Local Future Memory）

- AFM 包含 12 个可学习的 512 维 slot：4 个视觉 slot、4 个左触觉 slot、4 个右触觉 slot。
- 每个模态使用固定相位锚点：\(C = \{0.125, 0.375, 0.625, 0.875\}\)。
- 注意力得分引入高斯软相位先验：
  \[
  \text{score}^h_{k,i} = \frac{(q^h_k)^\top k^h_i}{\sqrt{64}} - \frac{(\phi_i - c_k)^2}{2 \times 0.18^2}
  \]
  即，内容注意力可以在所有有效位置中选择，但相位接近锚点的位置会受到偏好。
- **AFM 关键路由模式**：
  \[
  H \leftarrow H, \quad L \leftarrow (L, H), \quad R \leftarrow (R, H)
  \]
  即：视觉记忆只读取未来视觉；每个触觉记忆同时关注**自身的触觉流**和**相位对齐的未来视觉流**；**左右触觉之间互相阻断（L↔R 禁止）**。
- 对比条件 IFM（Modality-Isolated Future Memory）的路由为 \(H \leftarrow H, L \leftarrow L, R \leftarrow R\)，完全隔离各模态。
- 关键机制：每个触觉 slot 在拼接自身触觉序列和视觉序列上执行**一次联合注意力**，而非先读触觉再读视觉。

### ACT 集成与优化目标

- 当前视觉/触觉观测由冻结的 UniVTAC-ACT* 编码器处理；未来 slot 乘以零初始化的 tanh 门后注入 ACT 编码器记忆：
  \[
  [z_0 + s_1, q, s_2, \ldots, s_{12}, M_{\text{current}}]
  \]
- ACT 解码器使用 50 个动作查询，输出 \(50 \times 8\) 的归一化动作块；重叠块用权重 \(\exp(-0.01 \times \text{age})\) 聚合。
- 关闭 CVAE/动作编码器（latent z 恒为零），当前编码器冻结，仅训练未来编码器、时间滤波、slot reader、ACT transformer 和动作头。
- 唯一优化目标为掩码动作 L1 损失：
  \[
  \mathcal{L}_{\text{action}} = \text{mean}(|\hat{a} - a| \odot \mathbf{1}_{\text{not-pad}})
  \]

## 实验设计

### 数据集 / Benchmark

- 使用 **UniVTAC 仿真基准**七项接触丰富操作任务：Put Shelf、Pull Out Key、Lift Bottle、Insert HDMI、Insert Hole、Insert Tube、Lift Can。
- 所有任务均使用左右触觉流；Insert Tube 和 Lift Can 使用头+腕双摄像头，其余任务使用头部摄像头。
- 数据划分：每个任务训练与评估使用不同 episode 范围（如 0–39 或 0–49 训练，50–99 评估；Put Shelf 另有 40–49 开发集），每次评估 50 个 rollout，共 350 个 rollout。

### 对比方法与条件

- **UniVTAC-ACT\***：官方发布的 ACT 基准策略（本文对该基准策略的实例化）。
- **AFM Oracle**：训练和评估均读取 oracle 未来，使用非对称路由。
- **IFM**：与 AFM 完全相同的设置，仅将路由改为模态隔离（Eq. 10），移除 H→L 和 H→R 的读取边。
- **AFM Forced-Zero**：使用 Oracle 训练好的检查点，但评估时将所有未来记忆 slot 置零。
- **AFM Zero-Train**：整个训练和评估过程完全不读取未来 HDF 数据，在 future 模块前注入常量 \(12 \times 512\) 零。

### 公平性控制

- 所有 AFM-family 条件保证相同的 50 行 episode/reset 映射、外部评估器、预处理、归一化、时间聚合、rollout 时间范围、早停、相机协议和不可变厂商成功谓词。允许的唯一差异是检查点及表达指定未来信息条件所需的最小适配器。

## 资源与算力

- **GPU**：2 × NVIDIA RTX 4090 D（24 GB）
- **CPU/内存**：Intel i9-14900K，128 GB RAM
- **训练步数**：2000 optimizer steps
- **批次设置**：per-GPU micro-batch 为 1，梯度累积 8，有效 batch size 为 16
- **优化器**：AdamW，学习率 \(10^{-5}\)、权重衰减 \(10^{-4}\)；门参数使用学习率 \(10^{-3}\) 且无权重衰减；余弦退火至 \(10^{-6}\)；梯度裁剪 1.0
- **软件环境**：Ubuntu 20.04.6、PyTorch 2.7.0+cu128、Isaac Sim 4.5.0、Isaac Lab 0.41.3
- **精度**：FP32 训练（无 AMP）；未来编码的 chunk size 为 8（内存优化，不改变模型定义）

## 实验数量与充分性

### 实验数量

- **7 个不同任务**的完整对比，每个任务 50 个 rollout，共 350 个 rollout 的统计量。
- **5 个对比条件**：UniVTAC-ACT*、AFM Zero-Train、IFM、AFM Forced-Zero、AFM Oracle。
- **两组关键消融**：(1) 路由消融（AFM vs IFM）；(2) 未来使用性消融（Oracle vs Forced-Zero vs Zero-Train）。

### 充分性评估

- **优点**：受控变量清晰——IFM 与 AFM 的唯一差异是路由边；Forced-Zero 证明了策略确实在使用测试时的未来内容而非仅受益于额外模块；Zero-Train 证明了没有未来信息时策略路径仍然有效。实验在任务层面提供了细致分析（如 Put Shelf 和 Pull Out Key 的未来价值最明显、Insert Tube 中 Oracle 与 Forced-Zero 持平、Insert Hole 是唯一 IFM 最高的任务）。
- **局限**：实验完全在仿真中进行，无真实机器人验证；仅与 UniVTAC-ACT* 基线比较，未与其他 SOTA 触觉世界模型（如 Dream-Tac、Tactile-WAM、VT-WAM）直接对比；训练步数较短（仅 2000 步），模型可能未完全收敛；部分任务成功率很低（如 Lift Bottle 16%、Insert Hole 4%），统计差异可能不够显著。

## 主要结论与发现

1. **AFM Oracle 显著优于所有对比条件**：七任务平均成功率 32.0%（112/350），远超 IFM 的 23.7%（83/350）和 UniVTAC-ACT* 的 14.9%（52/350），绝对提升约 17.1 个百分点。
2. **非对称相位对齐路由优于模态隔离**：AFM 与 IFM 在同一 oracle 提供者、同一记忆预算、同一训练与优化设置下的差距（8.3 个百分点）证明：相位对齐的视觉上下文能让触觉未来记忆对动作生成更具可操作性。
3. **接口处的显式融合是有价值的**：尽管所有模态 token 在后续 ACT 编码器内仍可再次互相注意力交互，AFM 在接口处显式进行的非对称融合仍带来增益——说明下游自注意力无法完全弥补接口设计的信息组织差异。
4. **Oracle 训练的策略确实在使用未来内容**：从 Oracle 的 32.0% 降至 Forced-Zero 的 19.4%，表明策略不是仅靠附加模块收益，而是真实消费了测试时的未来信息。
5. **无未来信息时策略路径依然强健**：AFM Zero-Train 达到 20.0%，AFM Forced-Zero 17 为 19.4%，两者均高于 UniVTAC-ACT* 的 14.9%，说明 AFM 兼容的策略路径在不依赖未来输入的情况下也表现良好。
6. **任务级差异显著**：Put Shelf（54% vs 42%）和 Pull Out Key（54% vs 22%）从未来内容中获益最明显；Insert Tube 中即使测试时关闭未来（Forced-Zero 42% = Oracle 42%），策略增益也能保持；Insert Hole 是唯一 IFM 超过 AFM 的任务，但所有条件都接近成功率下限（2%–8%）。

## 优点

- **清晰的变量解耦**：OVTF 通过固定未来提供者，将"预测质量"与"接口质量"两个纠缠因素分离，是研究 WAM 接口问题的创新方法论。OVTF 的贡献不在于提出新的世界模型，而在于构建了一个能单独回答接口问题的诊断框架。
- **控制严格的消融设计**：AFM 与 IFM 的对比消除了除路由以外的所有差异；Forced-Zero 和 Zero-Train 设计分别控制了"未来是否被使用"和"训练是否见过未来"两个可能混淆的因素。
- **简洁有效的接口机制**：AFM 采用高斯软相位先验而非硬窗口，使内容注意力仍可跨相位选择；门控初始化为零避免了扰动预训练策略；阻断跨触觉访问的设计防止了不必要的左右手信息耦合。
- **部分任务上巨大增益**：Pull Out Key 从 22% 提升到 54%（+32 个百分点）、Lift Can 从 0% 提升到 30%，展现了 oracle 未来在接触丰富任务中的显著指导价值。
- **基线之上的一致性**：即便在完全无未来信息的条件下（Zero-Train 20.0%、Forced-Zero 19.4%），AFM 兼容路径仍优于官方基线，表明框架并非牺牲基础策略能力来换取未来信息的收益。

## 不足与局限

- **仅在仿真中验证**：所有实验基于 UniVTAC 仿真，未做真实机器人部署实验。仿真中的 oracle 未来在真实场景中不可获得，o2x 实际部署时需要学习式预测器，其预测误差对接口的影响并未研究。
- **缺乏与真实学习式预测器的对比**：论文只对比了 oracle 未来和零未来两个极端，没有与真实学习式未来预测器组合使用的实验，因此无法说明"当未来预测不完美时"AFM 的鲁棒性。
- **任务难度覆盖不均**：Lift Bottle（16%）和 Insert Hole（4%）的成功率过低，这些任务的统计区分度不足；且 50 次 rollout 的样本量对低成功率任务而言可能不够稳定。
- **训练规模较小**：仅 2000 优化器步骤、有效 batch size 16、FP32 精度，可能没有充分挖掘 ACT transformer 容量；未报告检查点选择与方差分析（如多次随机种子）。
- **与 SOTA 对比不足**：未与 Dream-Tac、Tactile-WAM、VT-WAM 等近期触觉世界动作模型比较；仅以 UniVTAC-ACT* 为基线，无法说明 AFM 在更广的方法空间中的相对位置。
- **评估指标单一**：仅用成功率衡量，缺少对抓取/接触质量的细粒度分析；未报告触觉预测自身的准确度或视觉未来与触觉未来的一致性度量。
- **领域漂移风险**：部分论文引用的参考文献（如 arXiv:2602.10093、2602.15922 等）日期标注异常靠前（2026 年），其可验证性和可信度需读者注意。
