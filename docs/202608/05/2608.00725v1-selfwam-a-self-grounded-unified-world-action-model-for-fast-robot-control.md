## 摘要
世界动作模型（WAM）通过联合建模动作和未来观测来提升机器人策略学习。然而，仅以任务提示和观测上下文为条件进行未来预测，可能会捕捉到通用的任务进展，而非所执行动作的具体后果。我们提出了SelfWAM，一种基于模态特化的Transformer混合体（MoT）架构构建的统一自接地WAM，它联合预测动作、动作条件下的未来RGB帧以及机器人自遮挡掩码，从而将未来预测接地于机器人可见身体及其动作引发的运动。在联合训练过程中，SelfWAM允许未来视觉查询关注示范动作的干净副本，将视频分支转变为动作特定的后果模型，同时保持仅使用动作的快速推理路径不变。为了将视频学习聚焦于与动作相关的视觉变化，我们对未来的机器人自遮挡掩码预测使用提示特定的目标，这消除了外观细节，并提供其时间演化与条件动作紧密耦合的目标。干净的动条件设置和未来的自遮挡掩码监督共同使未来预测更直接地反映执行动作如何改变机器人可见运动和周围场景。在RoboTwin 2.0和现实世界操控任务上的实验表明，SelfWAM能产生对动作更敏感的未来预测，同时保持快速策略推理，并提升策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- 现有 World Action Models（WAMs）通过联合建模动作与未来观测来提升机器人策略学习，但已有方法（如 FastWAM）在预测未来视频时仅以当前观测、语言指令和本体感觉为条件，没有显式利用“产生该未来”的示范动作。
- 这种“动作无关”的未来预测容易退化为捕捉通用的任务进展，而非区分不同动作带来的具体视觉后果，因此无法为策略提供真正的动作因果监督。
- 论文主张：面向策略的世界模型不仅应预测“接下来会发生什么”，还应回答“在当前动作下会发生什么变化”“变化发生在哪里”“机器人自身如何参与这些变化”。
- 为此提出 **SelfWAM**：一个自接地（self-grounded）的统一世界动作模型，通过“干净示范动作条件 + 机器人自掩码未来预测”，使未来预测显式地由所执行动作驱动，同时保持快速的动作直推（action-only）推理路径。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：
  - 将未来预测从“观测条件”变为“观测+动作条件”，让共享视频主干显式建模动作导致的视觉变化。
  - 引入机器人自掩码（self-mask）作为辅助预测目标，去除外观、纹理、光照和背景等与动作无关的干扰，聚焦机器人自身可见运动。
  - 通过非对称信息流设计，保证动作策略路径与部署时一致，避免未来信息或干净动作标签泄漏到策略预测中。

- **整体架构**：
  - 基于 FastWAM 的“双流混合 Transformer（Mixture-of-Transformers, MoT）”架构。
  - 视频流：预训练视频扩散主干（WAN2.2-5B），处理当前观测和噪声化的未来视频潜变量。
  - 动作流：轻量动作专家（从视频主干权重插值初始化），处理噪声化的未来动作 token。
  - 语言与本体感觉条件同时注入两个流。

- **非对称注意力信息流**：
  - 设当前上下文 token 为 O，噪声未来动作 token 为 eA，干净示范动作 token 为 A，噪声未来视觉 token 为 eV。
  - 三个查询组的注意力规则为：
    - Q_eA → {O, eA}（策略侧只能看到当前上下文和自己的噪声动作）；
    - Q_eV → {O, eV, A}（未来视觉查询额外关注干净示范动作）；
    - Q_A → {O, A}（干净动作只与当前上下文及其自身交互）。
  - 干净动作副本采用与噪声动作相同的动作 tokenizer、动作块、时间位置编码，但时间步嵌入设为 t = 0，表示“无噪声条件”。
  - 该设计使未来视频预测成为“动作条件后果模型”，同时保证策略路径与部署一致：部署时省略干净动作流和未来视觉流，仅保留轻量动作专家进行迭代去噪。

- **机器人自掩码预测**：
  - 同一视频主干通过不同 prompt 区分目标任务：RGB prompt 预测未来 RGB，self-mask prompt 预测未来机器人二值掩码视频。
  - 观测均为 RGB，掩码仅作为视觉预测目标；掩码示例不提供动作监督，不计算策略损失。
  - 掩码目标与 RGB 目标共享相同的时间偏移、空间布局、噪声调度和位置编码，但消除了外观细节，使语义监督更紧密绑定于动作引起的机器人运动。

- **训练目标**：
  - 使用标准 flow-matching 损失：L = λ_act · L_act + λ_video · L_rgb/mask。
  - 实验中 λ_act = 1，λ_video = 1；RGB 与自我掩码实例按 9:1 比例采样。

## 6. 论文的主要结论与发现

- SelfWAM 在 RoboTwin 2.0 上的成功率（clean 92.16%，randomized 93.08%，平均 92.62%）优于所有基线，包括 FastWAM（91.82/91.86/91.84），尤其在场景随机化下提升更明显。

- 相较 FastWAM 的观测条件未来预测，SelfWAM 的动作条件未来预测在 LPIPS、PSNR、FVD-I3D 上均显著提升，说明未来视频与示范未来更一致。
- 动作扰动与插值实验证明 SelfWAM 的未来预测对动作条件敏感且方向正确；动作无条件基线几乎不随动作变化。
- 消融表明：仅加干净动作条件对策略性能影响不大；再叠加自掩码监督后策略性能明显提升，说明自掩码作为“具身化”监督信号更有价值。

- 总体结论：自接地未来预测（干净动作条件 + 自掩码目标）能提升世界模型的动作因果性，同时不牺牲快速策略推理。

## 7. 优点

- 问题定义清晰，切中现有 WAM 未来预测“动作无关”的弱点，动机有说服力。
- 非对称信息流设计巧妙：既让未来的视觉分支看到干净动作，又不泄露给策略分支，保持部署时 action-only 路径不变。
- 将预测目标扩展到“机器人自掩码”是一个有洞见的做法，能有效抑制与动作无关的外观干扰，把模型注意力引导到机器人自身运动上。
- 在统一架构中同时支持 RGB 预测、掩码预测和策略推理，通过 prompt 切换输出域，设计简洁、灵活。
- 实验体系较完整：模拟 + 真实、多基线对比、未来质量指标、动作敏感性分析、消融、效率测试均有覆盖。
- 推理开销近乎零增长，工程实用性较强。

## 8. 不足与局限

- 自掩码标签依赖分割工具：仿真中可用真值，但真实场景需额外用 RoboSeg 离线生成，引入了标签噪声；且自动分割在遮挡、多机器人或复杂光照下的质量未做深入讨论。
- 未来预测质量评估（LPIPS/PSNR/FVD）仅针对训练分布中的轨迹，不是严格意义的 held-out 视频泛化评估。
- 真实实验规模较小：4 个任务，每任务 10 次，统计显著性有限，且只用了单一种类的灵巧操作（拾取-放置类），未覆盖插拔、装配、接触丰富任务。
- 自掩码监督与 RGB 监督按 9:1 简单加权，未对不同任务或不同机器人调整最优比例。
- 未显式建模接触力、力反馈、遮挡下交互，对接触丰富或部分可观测场景的支持有限（论文 limitation 部分也承认）。
- 论文对未来预测“动作敏感性”的度量仍以视频特征相似度和方向扰动为主，并未直接验证预测是否在物理意义上正确（如是否违反几何约束）。
- 训练成本较高，需要 64 张 A800 运行约 30 小时，对一般研究团队的复现门槛较高。
