## 摘要
世界动作模型通过迭代去噪生成固定时域的动作块，这会产生大量的推理延迟，导致机器人执行过程中出现暂停、动作过期和中断。我们提出了一种异步部署策略的实证研究，该策略将模型推理与动作执行重叠，以实现响应迅速且平滑的控制。我们在一个10 Hz双臂机器人上比较了六种策略，包括同步执行、纯异步切换、事后动作混合、去噪时混合、推理时速度引导和前缀条件生成。评估结合了离线轨迹分析和在线实验，涵盖动态操作、高精度放置和长时域任务。我们的结果确定观测、预测和执行命令之间的精确时间对齐是基本要求。对齐误差会产生持续的块边界不连续，仅靠混合无法纠正。在正确对齐的情况下，直接动作加权提供了简单平滑的基线，但在高精度任务中牺牲了准确性。推理时速度引导在我们的平台上无法可靠地约束已提交的动作。相比之下，前缀条件生成通过训练期间学习一致的动作延续，在任务性能、执行速度和轨迹平滑度之间实现了最佳总体平衡。这些发现阐明了异步部署策略之间的实际权衡，并为在实时机器人系统中部署高延迟世界动作模型提供了指导。

## Abstract
World Action Models generate fixed-horizon action chunks through iterative denoising, creating substantial inference latency that can cause pauses, stale actions, and discontinuities during robotic execution. We present an empirical study of asynchronous deployment strategies that overlap model inference with action execution to enable responsive and smooth control. We compare six strategies, including synchronous execution, pure asynchronous switching, post-hoc action blending, denoising-time blending, inference-time velocity guidance, and prefix-conditioned generation, on a 10 Hz bimanual robot. Evaluation combines offline trajectory analysis with online experiments across dynamic manipulation, precision-critical placement, and long-horizon tasks. Our results identify accurate temporal alignment between observations, predictions, and executed commands as a fundamental requirement. Alignment errors produce persistent chunk-boundary discontinuities that cannot be corrected through blending alone. With proper alignment, direct action weighting provides a simple and smooth baseline but sacrifices accuracy in precision-critical tasks. Inference-time velocity guidance fails to reliably constrain committed actions on our platform. In contrast, prefix-conditioned generation achieves the best overall balance between task performance, execution speed, and trajectory smoothness by learning consistent action continuations during training. These findings clarify the practical trade-offs among asynchronous deployment strategies and provide guidance for deploying high-latency World Action Models in real-time robotic systems.

## 一、核心问题与整体含义

### 研究动机

世界动作模型（World Action Models）是同时推理感知与动作、预测机器人运动的生成模型，在多种操作任务中展现了出色的灵巧性。这类模型基于扩散策略（Diffusion Policy），通过迭代去噪预测固定时域（fixed-horizon）的动作块。然而，这种推理范式带来一个关键工程难题：

- **推理延迟高**：端到端管线（相机采集→网络传输→迭代去噪推理→指令下发）总延迟可达数秒级别；
- **执行不连续**：机器人必须在新预测到来前冻结动作或重复旧动作，产生可见的块边界断裂；
- **闭环率受限**：有效闭环频率受限于推理频率，在推理窗口内无法对突发环境变化做出响应。

### 核心研究问题

论文的核心问题是：**如何在高延迟世界动作模型上实现既响应迅速又平滑的实时控制？** 具体而言，论文系统比较了六种异步部署策略，回答以下问题：推理与执行重叠后，相邻动作块在重叠区域必然发生预测不一致——如何最有效地化解这种不一致？

## 二、方法论

### 核心思想

异步推理（Asynchronous Inference）——在当前动作块尚未执行完毕时就触发下一次推理调用，使计算与执行在时间上重叠。但由此产生的新问题是：相邻动作块在重叠区域存在预测分歧，简单拼接反而会导致与同步执行相同甚至更严重的抖动。论文将已有的解决策略归纳为四大类，并以工程视角首次将其置于统一框架下实证比较。

### 形式化定义

论文定义了四个关键量：

- **H**：预测时域（每个块的帧数），实验中 H=24；
- **s**：执行时域——触发下一次推理前从块 n 执行的帧数（s < H），实验中 s=4；
- **d**：真实端到端管线延迟（帧数），受网络抖动、GPU调度等因素影响而波动；
- **d_est**：部署控制器使用的估计延迟，实验中设为端到端延迟的中位数（8帧）。

### 动作块的分区结构

异步模式下，块 n+1 的 H−s 帧重叠区被分为两个子区域：

1. **延迟区（Delay region，d_est 帧）**：块 n 已提交的帧，理想情况下块 n+1 应与之完全一致；
2. **剩余重叠区（Remaining overlap，H−s−d_est 帧）**：越远离当前时刻，块间分歧越大；
3. **非重叠区（Non-overlap region，末尾 s 帧）**：块 n+1 独有的预测。

**关键风险**：若真实延迟 d > d_est，控制器切换时访问的帧索引与机器人实际状态不对应，会产生位置硬跳变，且任何混合算法都无法修复。

### 六种部署策略

| 方法 | 机制 | 是否需要重训练 | 推理开销 |
|------|------|:---:|:---:|
| **sync** | 等待推理完成再切换，边界处暴露全部延迟 | 否 | 无 |
| **async** | 纯异步切换，不混合，在 d_est 处硬切换 | 否 | 无 |
| **async+blend** | 推理后对相邻块动作进行加权插值混合 | 否 | 低 |
| **simple** | 去噪过程中将重叠区预测动作与块 n 的约束动作加权混合 | 否 | 低 |
| **infer** | 推理时调整去噪速度场，将去噪轨迹引导向块 n 的一致性 | 否 | 中 |
| **train** | 训练时将块 n 的已提交前缀作为干净条件信号注入，学习生成一致延续 | 是 | 无 |

### 关键技术细节

- **事前动作加权（async+blend）**：仅需精确时间对齐和加权平均，是最简混合基线；
- **去噪时加权混合（simple）**：权重 w(t)=1（t≤d_est）逐渐衰减至 t=H−s 时为零；强插值带来最优平滑性但引入精度−平滑度权衡；
- **推理时RTC（infer）**：修改去噪速度而非生成的动作本身，理论上保留模型原始预测更多，但只在速度层级引导，无法对输出动作施加硬约束；
- **前缀条件（train）**：权重为阶跃函数——延迟区完全约束、其余区域不受约束；代表方法是 Training-Time RTC 和 Legato；需要重训练但推理零开销。

## 六、主要结论与发现

1. **时间对齐是根本前提**：观测、预测与执行命令之间精确的时间对齐是异步部署最基本也是最重要的工程需求。对齐差会导致持续抖动，任何混合算法都无法弥补。

2. **纯异步切换不可行**：async 在所有方法和所有指标中产生最高误差和最大 jerk，没有混合的异步切换在无精确时间对齐时不具可行性。

3. **事后混合是有效基线**：async+blend 仅凭精确时间对齐加简单加权平均，即可在低精度任务中产出合格轨迹——是"能用的地板"。

4. **推理时速度引导在本文平台上失败**：infer 的 Δdelay 显著高于动作约束类方法，速度级引导只能调整去噪方向，无法对输出动作施加硬约束，不能保证块边界的动作连续性。

5. **前缀条件方法最佳**：train 在所有任务中实现最佳总体表现——在任务完成分数、执行速度和轨迹平滑性间达到最优平衡（Pick Up Conveyor 96分、Block Into Slot 70分且速度最快、Food Into Microwave 96分且比 sync 快16秒）。

6. **同步执行仍有竞争力但动态任务失灵**：sync 在非动态任务中表现良好，但在动态任务中完全失败（Pick Up Conveyor 仅20分），且在所有任务中普遍最慢。

7. **精度−平滑度权衡确实存在**：simple 的激进插值带来最优平滑性，但在接触关键的高精度任务中显著牺牲精度（Block Into Slot 仅27.5分）。

## 七、优点

1. **统一比较框架**：首次将四类离散的异步部署方法族（纯切换、事后混合、去噪时引导、前缀条件）置于同一平台、同一评价体系下进行实证比较，提供了清晰的对比基线。

4. **明确提出时间对齐的重要性**：将被视为"工程细节"的时间对齐问题提升为核心发现之一，有助于社区重视该问题。
5. **多组件分项分析**：手臂/躯干/头部/夹爪分别报告误差，可定位特定输出通道的问题。

7. **诚实报告负面结果**：明确说明 infer 在本文平台上的失败，以及 simple 的精度代价，没有选择性报告。

## 八、不足与局限
