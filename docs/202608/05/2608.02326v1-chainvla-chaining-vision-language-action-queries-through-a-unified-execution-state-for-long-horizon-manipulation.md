## 摘要
人类通过保留先前动作所建立的知识，同时不断调整正在进行的运动，来执行长时间跨度的操作。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时都从当前输入重复规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个12亿参数的VLA策略，通过联合且可修改的执行状态来链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带从观察中得出的任务进度，而运动尾部将先前预测的未执行延续部分输入状态构建和动作生成。这两个组件共同调节一个解码器，该解码器在最新观察下重新生成每个动作时间范围，使携带的状态能够指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而移除运动尾部或进度上下文分别将RMBench成功率降低至11.2%和3.0%。这些不对称的消融实验与运动连续性有助于保留推断任务进度所依赖的观察流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

## 一、核心问题与研究动机

论文聚焦长时程（long-horizon）机器人操作中**跨查询（cross-query）交接不完整**的问题：

- **背景**：动作分块式 VLA 策略通过重复的“滑窗式”查询执行长任务——每次预测一段有限动作序列，执行严格前缀，然后重新规划。连续查询在时间上相邻，但每次动作块都从当前观测、本体感受状态和指令重新生成，**没有显式交接上一查询推断的任务进度，也没有交接其预测中未执行完的延续动作**。
- **两个层面的歧义**：
  - **任务层**：当前视角可能已无法恢复早期的任务证据（如 RMBench 的 Put Back Block 任务，同一观测与指令可对应不同历史，需要不同决策）。
  - **运动层**：重新规划丢弃了未执行的延续动作，即使当前位姿相似，新预测的前缀也可能与它所替代的运动不一致。
- **已有方案的困境**：记忆增强策略只保留观察派生的长期证据（无法携带“策略自身上一刻的意图”）；时序集成（Temporal Ensemble）等只保留短期运动一致性（无法回溯任务证据）。二者相互割裂。
- **核心研究问题**：如何让 VLA 策略在跨查询时同时衔接“任务进度”与“运动延续”，同时保持每次预测对最新观测的响应性？

## 二、方法论

### 1. 核心思想
引入**统一的、可修改的执行状态** \( s_k = (g_k, u_k) \)，在连续查询之间传递：

- **进度上下文（Progress Context）\( g_k \)**：携带观察派生的任务进度，由循环工作状态（Working State）与稀疏事件记忆（Sparse Event Memory）融合得到。
- **运动尾（Motion Tail）\( u_k \)**：携带前一预测的未执行后缀，作为“延续先验”输入状态构建和动作生成。
- 解码器在最新观测下**重新生成完整动作范围**，使携带状态成为“可修改先验”而非固定计划。

### 2. 关键公式与流程

查询转移（query transition）：
\[
(A_k, W_k, C_{k+1}) = F_\theta(x_k, D_k, W_{k-1}, C_k, u_k), \quad u_{k+1} = \text{Tail}(A_k)
\]
其中 \( x_k = (o_k, r_k, \ell) \) 为观测/本体/语言输入，\( D_k \) 为已执行动作历史，\( W_k \) 为工作状态，\( C_k \) 为事件记忆，\( \text{Tail}(A_k) \) 为预测但未执行的 \( H - h_{exec} \) 步后缀。

**工作状态更新**：学习的工作查询（working queries）通过交叉注意力编码当前多模态 token，并结合上一轮 live tokens 做循环更新；带掩码（episode 起始为零）与有界 FIFO 缓存。

**稀疏事件记忆**：存储有序事件 \(\{(κ_i, E_i, b_i)\}\)，每事件含 64 个视觉 token、8 个 Stage Info token、8 个时间 token 及检索键；检索采用**年龄感知的余弦相似度评分**（32 个年龄桶），锚点事件 + 最高分非锚点事件被读取。

**运动尾两条模型侧通路**：
- 编码为尾 tokens，加入工作状态构建；
- 对齐轨迹初始化解码器状态：\( \tilde{A}^{(0)}_{k+1} = \mathcal{I}(u_{k+1}) + \sigma_u \epsilon \)（加性高斯噪声）。

**训练细节**：按 episode 顺序展开同一转移；后续查询以 0.5 概率使用前置的 detached 尾；损失 = 条件流动作目标 + 阶段监督（若有标注）+ 重叠一致性正则化（权重 0.2）。

## 九、值得注意的深层含义与开放问题

1. **“任务进度”与“运动延续”的次序依赖**是本文最有洞察力的一点，但它在方法论上的启示可能超出 VLA：任何在“感知-记忆-规划-控制”闭环中做跨周期状态传递的系统，都必须先保证**执行层不偏离历史经验所对应的观测流**，否则上层的长期记忆会失效。这类似于强化学习中的“分布漂移”问题，但发生在推理时而非训练时。
2. **“作为先验而非计划”的设计哲学**是 ChainVLA 与之前方案的本质区别：MemER/MemoryVLA 把记忆当作**读入向量**，ChainVLA 把记忆当作**条件化的、可被新观测推翻的生成线索**。这提示跨查询一致性应该通过“让模型自己决定是否采用先验”的方式实现，而不是通过硬性拼接或时序平滑强制获得。
3. **后解码平滑的失败**代表了一个重要的警示：**在解码前把传递信息嵌入条件分布**与**在解码后对样本做集成/修正**，不是在优化同一目标的两种实现，而是两种不同的决策过程。前者允许模型产生更符合任务语义的动作样本，后者只能对已产生的动作做线性调和，无法生成“语义上不同”的决策。
4. **一个开放问题**：既然尾部对齐的初始化能帮助一致性，那么对动作后缀的**长度分布**（何时该长、何时该短）、以及尾在被新观测修改后**应保留多少原意**是否应学习得到？论文中的 \( H - h_{exec} \) 恒为固定后缀长度，若能自适应截断或许可进一步提升抗干扰能力。
5. **多模态 token 的记忆压缩方式**（64 视觉 token + 8 Stage Info + 8 时间 token）表明事件记忆的信息瓶颈很小，但论文未做“记忆写入时的信息损失是否影响最终成功率”的敏感度分析，这可能是未来迭代直接相关的调参维度。

---

## 十、总结性评价

ChainVLA 是一篇**问题意识清晰、方法设计统一、实验结构严谨**的 VLA 长程操作论文。它在核心贡献上做到了三件事：

- **识别了一个被主流方法忽略的层面错配**：连续查询之间不仅需要传递“任务做到哪了”（任务语义层），还需要传递“上一刻打算怎么动”（运动延续层），且两者之间存在依赖关系；
- **给出了一个极简而有效的统一机制**：将进度上下文（工作状态 + 稀疏事件记忆）与运动尾共同构造成可修改的执行状态，通过同一条件流解码器在最新观测下重新生成完整动作块，避免了“拼接式记忆”与“平滑式集成”各自的缺陷；
- **通过不对称消融证明了组件间的非独立性**：运动尾的移除比进度上下文的移除造成更大的性能塌陷，揭示了执行层历史对语义层记忆检索的先决作用——这一发现对后续长时程 VLA 设计具有直接指导意义。

同时，受限于仿真环境、单种子统计和外部基线不可比等因素，其结论的**定量力度**要弱于**定性洞察力**：最有说服力的不是具体数字，而是“64.4 个百分点的性能差如何由两个组件共同支撑”这一结构性证据。整体看，这是一篇**值得精读的、在方法设计与实验叙事上都有示范价值的论文**；其最大遗憾在于未能在真实机器人或异步控制条件下验证“边界一致性”的实际物理收益。
